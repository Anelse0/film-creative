局部改写 · scene-02〈海报〉· 只动被批评的那三句及其直接牵动处 · 已按本目录保存约定落盘。

**问题在哪一层**：在行动与措辞层，不在事件层。这场戏的事件（记者要"仇人"、两人贴到十厘米、白光、照片后来成了"年度最佳情侣"）都成立；攻击性来自三处写法——"一把抓住""拉近"是硬拽，"再走近一步试试"是威胁，"扣住手腕、也拧了一圈"是回击。三处叠起来，海报拍到的是一场真打，而后文要它读成"情侣"。

**改了什么**
1. 沈舟先笑之后加了一句挑衅"仇人啊。那你得凶一点。"——江砚的动作变成对一句激将的回应，而不是自发动手；这句也是他"嘴快、爱激人"的设定该有的话。
2. "一把抓住…拉近半寸" → "勾住泳帽带，往自己这边带了半寸。没用力，带子是松的。"——同一个动作、同一个距离，去掉力度。
3. "再走近一步试试" → "够近了吗。"——问的是记者，眼睛没离开沈舟。一句话对两个人说：给记者的是"这样够不够"，给沈舟的是另一层。江砚"说话少"的设定保留，只有这一句。
4. "反手扣住他的手腕，也拧了一圈" → "握住江砚勾着带子的那只手腕，没推开，也没松。"——沈舟没退这个故事事实保留，回应从反击改成不放手。

**保留了什么**：开场三句、"沈舟先笑了一下"、"沈舟没退"、"两人脸距十厘米。白光。"、记者的"好——就这个"、"两人同时松手。沈舟甩了甩手腕，走了。江砚看着他的背影，耳根是红的。"一字未动。"甩手腕"原来是拧过之后的动作，现在读成甩掉那个触感，仍然成立。

# scene-02 〈海报〉 · EP02 · 泳池边临时影棚 · 下午

摄影记者把两人推到白幕前，各穿队服，头发还是湿的。

摄影记者：面对面。近一点。像仇人一样。

两人转身。沈舟先笑了一下。

沈舟：仇人啊。那你得凶一点。

江砚看了他两秒，伸手勾住他的泳帽带，往自己这边带了半寸。没用力，带子是松的。他问的是记者，眼睛没离开沈舟。

江砚：够近了吗。

沈舟没退。他抬手握住江砚勾着带子的那只手腕，没推开，也没松。两人脸距十厘米。白光。

摄影记者：好——就这个。

两人同时松手。沈舟甩了甩手腕，走了。江砚看着他的背影，耳根是红的。
