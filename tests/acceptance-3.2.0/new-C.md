## 改了什么

问题在人物侧：原稿的攻击性不在那句台词，而在三个动作——"一把抓住"是突袭，"反手扣住手腕，也拧了一圈"是还手，"甩了甩手腕"是打完的收尾。三个连起来，观众看到的是两个人真动了手，摄影师那句"像仇人一样"反而成了多余的。而这张照片后面要成为队群里"年度最佳情侣"的梗，画面得是"看着像仇人、其实贴得太近"，不是"真打起来了"。

所以这版只动这三处，其余原文保留：

1. "一把抓住" → "两根手指勾住……往自己这边带了半寸。动作不快，够沈舟躲开的。沈舟没躲。"——抓的动作还在（故事正文和分集框架都写了抓泳帽带），但慢下来，给了躲的余地，攻击性变成了试探。
2. 台词不变，加一个"（声音不高）"。同一句"再走近一步试试"，慢动作、低声音之下是挑衅式的邀请，不是威胁。
3. "反手扣住他的手腕，也拧了一圈" → "抬手扣住江砚勾着带子的那只手腕，没使劲，就按在那儿。"——沈舟还是没退、还是抓了手腕（框架里写的是这个），但去掉"拧"：他不是还手，是把江砚的手按住不让松。
4. "甩了甩手腕" → "把帽带理了理"。没有打完的痕迹，只有被碰过的痕迹。

保留的：摄影师的指令和"好——就这个"、沈舟先笑、脸距十厘米、白光、两人同时松手、江砚耳根红。这些是照片成梗和结尾余味的依据，一个没动。

## 没选的改法

- **去掉肢体动作，只留对视**：攻击性一下就没了，但照片也没了——"抓泳帽带"是 02_story 和 EP02 框架里这张照片的内容，去掉动作等于换事件，超出"这段太强"的范围。
- **换掉那句台词**："再走近一步试试"在故事正文和框架里都有，也是后面梗图最可能配的字；问题不出在它，出在它前后的动作。留台词、改动作，下游改动最小。

## 整场全文（v02）

# scene-02 〈海报〉 · EP02 · 泳池边临时影棚 · 下午

摄影记者把两人推到白幕前，各穿队服，头发还是湿的。

摄影记者：面对面。近一点。像仇人一样。

两人转身。沈舟先笑了一下。

江砚伸手，两根手指勾住沈舟的泳帽带，往自己这边带了半寸。动作不快，够沈舟躲开的。沈舟没躲。

江砚（声音不高）：再走近一步试试。

沈舟不但没退，还抬手扣住江砚勾着带子的那只手腕，没使劲，就按在那儿。两人脸距十厘米。白光。

摄影记者：好——就这个。

两人同时松手。沈舟把帽带理了理，走了。江砚看着他的背影，耳根是红的。
