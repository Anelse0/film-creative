# 1.2.0 非盲文本产出

同一维护 Agent 按新版规则撰写的合成样本；不是外部测试者或独立模型结果。用于暴露规则冲突，不计胜率。D01/F01 的完整场景见 `scenes/`，实际汇编见 `reading.md`。

## D02 · 直接说与完整解释

**陈**

我不想继续经营了。这半年我每次到店门口，都想再绕一圈才进去。你问缺不缺人，我就说缺人；你问是不是账难做，我就说账难做。其实你把这些都解决了，我还是不想来。我想退出，也不想再拿一个你能解决的问题搪塞你。

**罗**

那我上星期跟你说再招个人，你为什么答应？

**陈**

我以为我答应下来，就能再撑一年。

**罗**

你不用撑一年。招聘我停了。已经答应来试工的那个人，你跟她解释。

检查：罗回应招聘这个具体后果，非借台词总结友谊；此处经营决定仍需后续协商，未声称退出手续已完成。长段没有被机械切碎。

## D03 · 喜剧群戏

**大姐**

先还我修冰箱的钱。分红之前，它是我一个人的冰箱，分红以后不能忽然变成大家的。

**二哥**

没人跟你抢冰箱。我是说剩下的钱再添个烤箱。

**小妹**

我那份别添进去。我不在店里，已经连续两次隔着手机拥有新机器了。

**二哥**

那就算我和姐买的。

**大姐**

你先把“和姐”去掉，让我看看还买不买得起。

检查：笑点来自替别人作财务决定和称谓调整；三人关注维修垫款、经营扩张、退出追加投资，信息不依赖新增秘密。仍需决定分配方式，不替他们草率达成一致。

## D04 · 风格化声音

**沈**

这一走，怕是往后的春天，都只能从你的信里看了。

**顾**

我写花开，向来比花开得早。你别信我的日期。

**沈**

日期可以不信。信还是要来的。

顾把写好的地址交给他。

检查：沈关注承诺，顾用自己的写信习惯回应；修辞仍构成交流，没有以“过于工整”为由改成碎句。文风本身仍是偏好判断。

**B**

车都到门口了。外套给你披，湿了算我的。

## S01 · 成功后的后半段

钱凑齐以后，林导第一次把排练计划交给志愿者。她原想请大家照着做，大家却问，既然每个人都在出时间，能不能自己定开演日。她没有拒绝，只把原定的日期擦了。

讨论一直拖到晚饭。舞台组要留足搭台的周末，前台组希望避开孩子的毕业典礼；每次有人说“我都行”，另一个人就替他定下来。林导听见那句自己常说的“我替你考虑过了”，终于插了一句话：没说的人，先别替他答。

他们定下一个比原计划晚两周的日期。林导重新排戏，删掉一段只有她喜欢、大家一直没敢说太长的谢幕。演出当晚，有演员在谢幕时先朝后台招手，搭台和售票的人也走上来。林导站在侧幕，没有照排练那样叫他们回去。她把原本留给自己说的话，交给了离观众最近的那个人。

检查：进展来自经费成功后“谁来决定”的既有处境，未加反派或资金问题。日期延后和谢幕改变是共享决策的实际代价；不是“团结很重要”的主题宣言。仍是一个可修订的故事方案，并非唯一正确写法。
