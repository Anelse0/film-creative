# 1.2.0 整体审查与验证

日期：2026-09-08。基线：v1.1.0（4df0ab409e9f801d1e451395640b4c8c18187e73）。本次审查覆盖入口、阶段协议、创作/对白方法、模板、执行契约及文件汇编；共用生产类型包维持交接边界。此次“整体 review”不代表穷尽所有创作类型或证明模型效果。

## 发现与修复

| 问题 | 后果 | 实施位置 |
|---|---|---|
| 台词指南重诊断、轻写出下一句 | Agent 可能列方法但仍交错独白 | `dialogue-design.md`：先写连续片段，转到听者，再比较实际改稿；接入 SKILL/S3c |
| 创意强制可见代价、短主控句；对白中的变化不算 | 安静、修辞或口头决定容易被误删 | 重写 S3a，新增成功后的后果、群像选择；接入 `creative-search.md` |
| 素材问题把脸/声音直接解释为谎言或性格 | 虚构被误记成已有事实 | S3a 分开可观察素材与虚构候选，沿用上下文证据边界 |
| 默认四部分输出、前置修订账本、模板多张表 | 读者需要穿过分析才能读作品 | `output-formats.md` 统一正文先行，精简三种模板，同步 intake/S3b/重写协议 |
| 故事模板结尾固定追问进入剧本 | 与自主执行和单阶段目标冲突 | 输出只附实际必要问题；执行契约说明计划顺序不是思考轨迹 |
| Markdown 台词四格缩进、场景正文混表演参数 | 对白被渲染为代码，阅读版难分层 | 场头/动作/人物/对白分开；说明放正文标记外；可选 Fountain 模板单独使用 |
| 汇编清单用绝对路径，无失效检查 | 移动项目、改源稿、改场序后难判断阅读版是否可用 | v2 相对路径清单与 --verify；兼容 v1 绝对路径 |
| 汇编可能覆盖源文件硬链接或人工阅读版，第二次写入失败留下半成品 | 源文件保护与文件一致性不足 | 身份/覆盖检查、双文件预暂存、常规失败回滚、恢复失败保留备份 |
| 旧正文缺内容却有外置场头、内外重复场头 | 空稿或重复标题流入阅读版 | 修复旧格式正文提取，保留有效旧输入 |

专业资料及已读范围见 [来源记录](../../references/craft-sources-1.2.0.md)。本次没有为文档体积添加通用编剧理论大全；每个新增方法有入口、实际写作动作与不适用边界。

## 实际验证

- `bash tests/run_tests.sh`：73 个 unittest 与既有 shell 回归通过。包含历史规则存在性检查与实际代码行为测试，不能都解释成行为测试或创意测试。
- 新增 13 个汇编测试覆盖：旧场头/空正文、跨目录迁移、源稿失效、阅读版改动、场序篡改、硬链接及派生文件路径、初次/再次写入失败、旧清单、坏清单、锁定空格/多行、填充真实模板、回滚失败恢复备份。
- `python3 scripts/assemble_script.py --verify tests/acceptance-1.2.0/reading.md`：来源哈希、阅读版哈希、顺序与正文重建一致。实际两个源稿和清单一并入库；CI 继续校验这份样稿。
- W01：临时保存含连续空格与重复台词的输入，字节相同；这只验证本次保存操作，未测其他 Agent 是否误启动创作。
- F01：在临时场景修改源稿一字后，旧阅读版验证以 `source changed` 失败；没有把故意过期清单提交进仓库。
- D05：原句含标点逐字出现一次；改动只在授权 B 句。D01–D04/S01 的非盲正文与具体检查见 [产出](responses.md)。

## 内容走查与局限

D01 的知识变化从第一场带入第二场，未提前和解；D02 保留完整说明；D03 人物由同一笔钱引出不同选择；D04 保留文雅风格；D05 用具体处境替换泛化金句且保护原句；S01 从筹款成功转向共同决策。这些样稿可供检查方法是否实际进入正文，但均由本次维护 Agent 编写及自评，**不独立、不盲、不构成新旧版胜率**。

尚未完成：真实长剧本/多轮长上下文压力测试、独立 Agent 对照、真人围读，以及 Fountain 目标软件渲染/PDF 排版验证。Fountain 只提供规范来源和模板，汇编器仅处理 Markdown。文件校验不证明戏好看、时长成立或故事无矛盾。并发修改、系统崩溃和持续 I/O 故障不保证双文件原子提交；需要按错误提示恢复并重新校验。
