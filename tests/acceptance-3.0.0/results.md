## 运行方式

- 输入与评价标准在改动前固定（`cases.md`）。六题：从零开发 ×2（T1 非爱情非体育、T6 当前题材）、诊断 T2、优化单集 T3、优化单场 T4（本来有效、不应过度修改）、优化对白 T5。
- 每题每版一个独立的 general-purpose 子代理（同一模型），只加载对应版本目录的 SKILL.md 与其引用文件，不联网、不运行脚本、限时 10–12 分钟、对话内交付。旧版六题先跑，新版六题后跑；旧版输出在改动新版前已落盘，之后未改动。
- 评审：`scripts/blind_eval.py pack` 随机映射 X/Y，评审前未打开 `key.json`；按 `cases.md` 六条标准逐对写判定与文本证据，再 `reveal`。评审者是维护 Agent 本人，**不是用户盲选**：评审者知道两版的写法差异，可能从格式痕迹（如新版的"四件事"表）猜到版本，结论只能算"非盲呈现改善"的上限估计，不能证明用户审美满意度或真实观众效果。
- 全部原文：`responses-1.1.0.md`、`responses-3.0.0.md`；映射与判定：`blind-key.json`、`blind-verdicts.json`。

## T5 复测与修复

T5 是唯一旧版胜出的一对，为区分波动与机制问题，两版各再跑一次（第二轮，**非盲**）：

- 旧版第二轮仍更好："我上了一夜班，回来就想东西都在原来的地方"把"我需要自己的空间"落成此刻的具体愿望，全程不提前男友。
- 新版第二轮把立场说成口号："可这是我家，东西扔不扔，我自己说了算""我是你妈，什么叫别人"。

两轮一致，判定为机制问题：新增的"有理由坦诚时允许直说 / 直说也有资格"被读成"可以直接表态"。修复：`character-scene-development.md` §五 与 `SKILL.md` 取向 6 明确"直说不等于表态；把立场落成此刻对这个听者的具体愿望或要求，从身体状态、职业习惯、关系里找说法"，并给出正反例；`stage-3c-script.md` §3c.5b 加"范围小不等于改得少：每个人有说这句的理由与自己的立场"。修复后新版第三轮 T5 结果附在下方；旧版未再跑。

### T5 第三轮（修复后，新版，非盲）——作废

第三轮输出明显好转，但复查发现我写进规则的正反例（"回来就想东西都在原来的地方""我需要自己的空间""我是你妈，不是别人"）直接取自本题输入与旧版输出，新版第三轮几乎照搬了正例句。这是测试污染，也违反本 Skill "示例不复用"的原则；第三轮不计入。已把规则里的正反例换成与测试无关的句子（"这周的排班别再替我改""你走之前把钥匙留下"；"我只是想被尊重""这是原则问题"），并用 grep 确认快照中不含测试原文。

### T5 第四轮（换例后，新版，非盲）

"不想。扔之前问我一句。"——小满对前男友只给一个字，要求落成一句可执行的话；母亲"我问了你也说不要……我不管谁管？"有自己的依据；"这周你在，家里的东西我自己收，你歇着"是此刻的具体安排。与旧版两轮相比质量相当，判定 tie：退步修到持平，未证明超过旧版。这是非盲、单样本的判断。
