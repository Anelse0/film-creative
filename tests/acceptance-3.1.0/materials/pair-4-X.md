**诊断一行**：问题在可见性层——前半场老周只被否定句描写（没看他、没动），观众看不到他在做什么，他的存在感全靠两句锁定台词和最后几秒的动作撑着，前面没有积累。

**改动清单（只加老周的动作，不加台词、不改事件）**

1. 开场：加"扳手每响一下，老周的烟就在嘴边停一下"——他没看儿子，但一直在听。解决：把"没看他"从缺席变成一种在场方式，也为锁定句"我听声"铺路。
2. "老周没动"之后：加裤兜里钥匙轻响一声。解决：结尾的钥匙串提前用声音出现，观众先听见再看见；他没动，但他手里已经在做决定。
3. "爸。"之后：加"老周这才转过头——看的是车，不是他"。解决：给锁定句一个可见的起势；保留"没看他"的性格，同时让他动。
4. 车倒出后：加"把头偏过去一点，耳朵朝着发动机"；掐烟改为"在凳子腿上掐了"；"走了两步又停下"落到"工具箱跟前"；加一句发动机"匀匀地转着，一声杂音都没有"。解决：他听声这件事被看见；停下有具体位置，也解释他为什么停——没有可挑的了。
5. 结尾：钥匙串明确"从裤兜里掏出"；出门经过车头时"手在引擎盖上按了一下，像试温度，脚没停"。解决：老周走出画面时仍有一个动作，父子之间唯一的一次触碰落在车上而不是人上。这一处带一点温度，是本轮唯一改变收尾质感的动作，不要可单独摘掉，其余不受影响。

**场 05 · 修车行 · 傍晚**

阿凯在举升机下拧最后一颗螺丝。老周（他父亲）坐在门口的塑料凳上抽烟，没看他。扳手每响一下，老周的烟就在嘴边停一下；响声停了，他才把那口烟吸完。

阿凯：好了。你试试。

老周没动。一只手插在裤兜里，兜里有东西轻轻响了一下。

阿凯：爸。

老周这才转过头——看的是车，不是他。

老周：（锁定）你先开出去，我听声。

阿凯发动车子，倒出车间。老周把头偏过去一点，耳朵朝着发动机。车尾灯照在老周脸上。他把烟在凳子腿上掐了，站起来，往里走了两步，走到工具箱跟前，又停下。外头发动机匀匀地转着，一声杂音都没有。

阿凯：（车窗里）怎么样？

老周：（锁定）行了。明天你自己来开门。

老周从裤兜里掏出钥匙串，放在工具箱上，走了。经过车头的时候，他的手在引擎盖上按了一下，像试温度，脚没停。阿凯坐在车里，没下来。
