## 第1集 〈楼道〉

**场1 · 老小区 3 号楼一楼楼道 · 上午**

墙上刚贴好的《加装电梯意向征询公示》胶水还湿着。程晚背着帆布包，用手掌把四角压平。

一只手从她身侧伸过来，把公示撕下，对折。

陆一鸣，工装围裙，左手食指缠着胶布，把折好的纸递还给她。

陆一鸣
　　这面墙是一楼的。贴东西先问一楼。

程晚
　　公示是街道办的，贴在公共楼道。（接过纸，展开）您是一楼住户？

陆一鸣
　　陆一鸣，一零一。楼下"陆记钟表"也是我。

程晚
　　程晚，街道办，负责这栋楼加梯。（把纸按回墙上）您有意见，协调会上说。

陆一鸣
　　说过了。三年前说过，前年说过。你是第三个。

他伸手又要撕。程晚用后背挡住墙。

程晚
　　这回不一样。六十天，签约到三分之二，补贴才批。

陆一鸣
　　那六十天以后就清净了。

楼梯上传来拖鞋一级一级蹭台阶的声音。两人同时抬头。

方美琴一手扶栏杆一手拄拐，从三楼半转角下来，每下一级先把好腿放稳。她看见公示，脸上亮起来。

方美琴
　　小程来了？（对陆一鸣）一鸣，又欺负人家小姑娘。

程晚
　　方老师，我三十一了。

方美琴
　　在我这儿都是小姑娘。

陆一鸣
　　方老师，您慢点。

他上前两级台阶伸手，被方美琴拍开。

方美琴
　　我下个楼要十二分钟。你数过没有？

陆一鸣没接话，退回楼道口。赵德海拎着两袋豆浆从单元门进来，一眼看到公示。

赵德海
　　好，贴上了好。（递一袋给方美琴）小程，一鸣是住户代表。这楼十二户，八户看他脸色。

程晚
　　那我先跟代表谈。

陆一鸣已经进了一零一，门带上。

**场2 · 陆记钟表铺门外 · 接上**

程晚绕到楼外。铺子玻璃窗上挂着"营业中"木牌，窗里靠着一排老座钟，阳光斜着打在工作台上。

她从包里抽出井道设计图，对着外墙比。井道落点——正好整面盖住这扇窗。

玻璃后面，陆一鸣坐到工作台前，抬眼看她一下，伸手把木牌翻过来："休息中"。

程晚把图纸叠回去，多捏出一道新折痕。

## 第2集 〈修表〉

**场1 · 陆记钟表铺内 · 次日下午**

墙上二十几只钟走得不齐。只有工作台角那只黑漆座钟停着，钟面下压着一张黑白照片。陆一鸣戴着目镜拆一只怀表。门铃响，程晚进来，把一张新图摊在工作台上。

程晚
　　井道东移一米二，不挡您的窗。

陆一鸣
　　（不抬头）东移一米二，压着楼道消防门。消防验收过不了，你自己再看一眼。

程晚低头看图，手指停在消防门的位置。

程晚
　　……我昨晚画的。

陆一鸣
　　看出来了。（放下镊子）钟坏了不是把所有轴都换掉，先找哪根卡住。

程晚
　　那您告诉我哪根卡住。

陆一鸣拿起镊子，继续拆。

程晚
　　陆师傅，我是合同工，这一单签下来才有转正。我不是来磨您的，我是没别的楼可去。

陆一鸣的手停了半秒，又动了。

门铃响。方美琴拄拐进来，拎着饭盒。

方美琴
　　一鸣，红烧肉，你爸爱吃的那个做法。（把饭盒放到图纸旁）你爸要是还在——

程晚的视线落到那只停着的座钟上。

陆一鸣
　　方老师。

他把饭盒推回去，推过图纸，推到方美琴手边。

陆一鸣
　　您教过我。您不能替我爸说话。

方美琴的手在饭盒盖上停了一下，拎起来。

方美琴
　　（对程晚）小程，我多出两万。你替我跟他说。

她出门，铃响。陆一鸣盯着怀表。

陆一鸣
　　她认两万。她认不了三楼那个二房东。

程晚
　　小周？

陆一鸣
　　三楼两套房，房东都在外地，全听小周的。他不点头，两票没了，楼上观望的也跟着他。

程晚手机震，屏幕：赵主任。她接起。

赵德海（画外）
　　小程，小周那票好办，他说条件当面谈。

程晚看陆一鸣。他把目镜按回眼眶，没再抬头。

## 第3集 〈三楼〉

**场1 · 3 号楼三楼过道 · 傍晚**

四扇隔断门，一扇门后传出炒菜声。小周靠在门框上刷手机。

小周
　　电梯我无所谓，租客爬三楼爬得动。有电梯，一间涨三百。房东那边我一个电话。

程晚
　　所以您签？

小周
　　有人举报我群租，信在你们街道。你帮我压一压。

程晚
　　举报我不能压。

小周
　　那我这两票跟一楼走。（把门带上）

**场2 · 3 号楼一楼楼道 · 接上**

墙上新贴一张红纸，手写大字：《关于个别住户阻挠加梯的通报》。赵德海站在边上，几户人围着陆一鸣。

住户甲
　　你一家挡十几家！

陆一鸣
　　图纸盖着我的窗，谁来跟我谈过？

楼梯上，方美琴一手栏杆一手拐，急着往下，到四楼半时膝盖一软坐在台阶上，拐杖滚下两级。

所有人停下。

陆一鸣第一个上去，蹲下，把她一只手臂绕到自己肩上，背起来。

陆一鸣
　　去六楼。

他背着方美琴往上走。程晚看了一眼，转身走到红纸前，整张撕下，叠好，递给赵德海。

程晚
　　赵主任，签约自愿。这张纸以街道办名义撤了。

赵德海
　　小程，你这是拆我的台。

程晚
　　您贴的时候也没问我。

赵德海把纸攥在手里，出了单元门。人群散开。

楼梯上脚步声。陆一鸣下来，额头有汗，经过程晚时停了一下。

陆一鸣
　　纸撕得对。字，我还是不签。

程晚
　　你怕的不是窗。

陆一鸣看她两秒，没答，推门进一零一。

程晚手机亮起。小周的消息：「压一压。我不光签，再帮你拉两票。」

她盯着屏幕，拇指悬着。
