需求识别：想故事 / S3a / 停在选方向 / 锁定与排除按原话；未落盘。

**默认地图**：翻旧照片落泪、身高刻度墙、父亲不肯卖最后妥协、大吵后和解。两个方向都不靠这些。

**方向一〈交付状态〉**

一句话：女儿以为今天是来告别，父亲却在按买家的验收单修房子——修那扇要抬着才关得上的窗。

人物：卖房是女儿定的，父亲要搬去她那边。他把这一天理解成最后一次尽职：房子得"能交出去"。女儿越想让他坐下，他越忙。

关系：女儿是决定者，父亲在执行；但在这间房里懂行的是父亲，女儿只能递工具。

事件：女儿发现父亲收拾的不是要带走的东西，是留给下一家的——哪扇窗要抬着关、水表在哪、楼下老太太几点睡，他在写一张纸条。女儿从"陪他告别"变成"帮他交付"：最后是她握着窗把手，父亲教她抬那一下。

观众：先以为父亲在逃避，看到纸条后明白，修理和交接就是他的告别方式。

主控画面：父女合力把窗抬起关严，屋里一下安静。

拍什么：从女儿进门看见父亲蹲着补墙，到两人把钥匙和纸条留在桌上。

风险：动作多台词少，容易拍成生活流水账。

**方向二〈后备箱〉**

一句话：女儿开车来，后备箱只装得下这么多，父亲每样都想带；她要他一件一件选。

人物：女儿把这一天理解成"帮他断舍离"，父亲理解成"能带多少带多少"。他往箱子里放的全是女儿小时候的东西——她早就不要的画、奖状、坏掉的随身听。

关系：女儿催，父亲拖延、讨价还价；中途买家提前来量窗帘尺寸，父女在外人面前立刻变成一致的"我们家"，买家一走又接着吵。

事件：女儿看清箱子里装的是什么，把自己的旧物搬上车，父亲的两把椅子反而留下了。谁在为谁保留，这句话从她嘴边过了一下，没说出口。

观众：靠"装得下吗、下一件选什么"的小悬念和幽默往下看，最后明白父亲舍不得的是女儿不在乎的那些年。

主控画面：后备箱盖合不上，女儿把自己的画塞进去，用力压。

拍什么：从打开后备箱到盖上后备箱，中间买家来了一趟。

风险：买家要有自己的事，不能只是打断工具。

**差异**：谁说了算、父亲怎样理解这一天（尽职 / 保留）、观众靠什么看下去（观察 / 悬念与幽默）都不同。

**推荐**：方向一更像 5 分钟能拍完的单一动作；方向二情绪回报更直接，但配角与节奏要求更高。你定：选哪个，或先试写一场？
