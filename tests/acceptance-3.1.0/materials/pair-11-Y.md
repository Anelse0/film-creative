**场 01 〈就我们三个〉 · 林家餐厅 · 晚**

三菜一汤。林建国的运动包靠在门边，没拆。他伸手去拿筷子时先看了一眼——筷筒已经挪到苏岚那一侧。

**林小满**
　　考完我哪儿都不去，就去一趟外婆家。就我们三个。

**林建国**
　　去。考完就去。

苏岚给小满盛汤，没接话。

**林小满**
　　妈？

**苏岚**
　　外婆那边得先打个电话。她腰不好，人多了忙不过来。

**林小满**
　　三个人叫人多？

**苏岚**
　　我是说得先说一声。

小满放下筷子。

**林小满**
　　还有。为什么最近家里安静得不像话？

**林建国**
　　我天天早训，不在家，能不安静吗。

**林小满**
　　不是那种安静。你回来了也安静。你们俩到现在一句话没对着说。

林建国夹起的一筷子菜停在半空，放回自己碗里。苏岚看着汤勺。

**林建国**
　　（对苏岚）汤给我盛一点。

苏岚接过他的碗，盛汤，递回去，两只手都扶着碗底。

**苏岚**
　　烫。

**林建国**
　　嗯。

小满看着那只碗从一只手到另一只手。

**林小满**
　　爸，你今晚住家里。明早你送我。

**林建国**
　　我五点就得起，别吵你妈，我睡书房。

**苏岚**
　　书房的被子我下午晒过了。

林建国看了她一眼。小满重新拿起筷子。

**本场说明（简）**
- 参数：强度高 / 方向内收 / 信息不对称（观众与父母知道，小满只有疑心）/ 密度中。
- 结束时变了什么：小满没拿到答案，但拿到了"爸今晚住家里"；两人为了她第一次当面说了话（"汤给我盛一点"——"烫"）；"被子下午晒过了"说明苏岚早知道他会留下——这是两人在协议之后仍在替对方安排的最后一点。
- 未决项：明早送考、外婆家之行是否兑现，属后续场次；如需接着写"考后告知"那场，或调整小满逼问的力度，请说明范围。进入分镜 / 表演外化 / Seedance Prompt 时由 film-director 承接。
