你是一位严格的剧本评审，第一次看这几部剧。下面有三组互不相关的写作任务，每组有同一任务的两个版本（版本 A、版本 B），你要判断每组里哪一版更值得拍。你看不到作者的任何说明，也不知道两版分别出自哪里。三组分开判，一组的结论不影响另一组。

目录 J = <scratchpad>/bench/judge

只读下面九个文件，不读其他任何文件。不用 ls / grep / find 查看其他文件或目录，也不打开 J 下的其他子目录。
- 第 1 组：任务 J/tasks/T1.md；观众在本场之前已经看过的正文 J/ctx/T1-context.md；两个版本 J/present/T1-order{K}.md
- 第 2 组：任务 J/tasks/T3.md；已看过的正文 J/ctx/T3-context.md；两个版本 J/present/T3-order{K}.md
- 第 3 组：任务 J/tasks/T5.md；已看过的正文 J/ctx/T5-context.md；两个版本 J/present/T5-order{K}.md

每组逐项比较（每项都要引原句为证，台词保持原文）：
1. 锁定与禁区：用户原话里要求原样保留的台词、必须发生的事、不许写的内容，两版各自守住没有。违规的一版直接判负（两版都违规写 both_bad）。
2. 复述：哪些句子是在复述观众已经知道的事（前几场说过、演过，或本场前面已经说过）、递话问句（答案下一句就给）、确认 / 接话、流程交代。两版各列出来并计数。
3. 推动者与转折：谁在出招（想从谁那里拿到什么、用什么办法），谁只是在接收；本场有没有转折（谁以为会怎样 → 实际怎样）。
4. 静音测试：关掉声音、只看动作和画面，能不能看懂谁想要什么、谁赢了或输了；靠的是哪个动作。
5. 观看欲望：观众在哪里得到心动、担忧、惊讶、好笑或释放。
6. 长度不是优点：做同样的事，更短的一版更好；也不要被漂亮的措辞打动。

每组输出格式（中文）：
- 版本 A：锁定 守住 / 违规（哪里）；复述类句子 N 句（逐句列）；推动者；转折；静音测试；最好的一处；最弱的一处
- 版本 B：同上
- 判定：A / B / tie / both_bad（只写一个）
- 理由：三句以内，引原句为证

三组都写完后，最后单独给一个汇总块，严格按这个格式（每行一组，判定只写 A、B、tie、both_bad 之一）：
汇总
T1: <判定> | <一句理由>
T3: <判定> | <一句理由>
T5: <判定> | <一句理由>

不要写任何文件。

（{K} = 1 或 2；两个评审代理各用一个顺序，彼此不共享上下文。J/tasks/ 是 tasks/Tn-judge.md，只含用户原话；J/ctx/ 是 ctx/Tn-context.md。）
