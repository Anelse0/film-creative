## 事件轨（写台词和正文前填；每行是一次变化，地点、活动、时间是它的属性）
一张表管两件事：谁此刻要什么（人物清单），以及观众在这几十秒里看见什么变了（每行一次变化）。**推进只数变化，不数地点**——换一个地点、跳一段时间，只有那里发生了一次变化才算数；写不出变化的行删掉，或并进上一行。`review_script.py` 逐字核对这张表与正文。

人物（本场说 ≥3 句的人，以及任何一行变化的主体——**不说话的人也在内**；每人一行）：
- **A**｜持续赌注：__（出处：`ip.md` / 故事 / 分集框架哪一行）｜此刻向 B 要：__｜怕：__｜为什么是现在：__

| # | 谁 → 对谁 | 变化：进 → 出（类别） | 说出口（逐字）／不说：理由；代价 | 删掉损失（观众少知道 / 少感到什么） | 地点（子空间） | 活动 | 时间 | 锚句（逐字） | 估时 s |
|---|---|---|---|---|---|---|---|---|---|
| 1 | A → B | B：__ → __（信息） | "__" | __ |  |  | — |  |  |

- **变化**写"谁：进 → 出（类别）"，类别取 得到 / 没得到 / 推迟 / 失去 / 信息 / 关系 / 决定 / 物件 / 地位；"推迟 / 没得到"在括号里接"；代价：__"。"谁"可以是"观众"（只改变观众所知）。进出相同、或与这个人前面某一行的"出"相同，都不算变化。
- 没有变化、只让刚发生的结果停一下的行，写"无（余韵：理由）"：可以留（"队伍跑进太阳"），不算推进；**余韵行不能换地点、不能跳时间**——把观众带到新地方，那里就得发生一次变化。
- **说出口**：这一行里"谁"说出自己要的那句，逐字加引号，正文里要一字不差；有理由不说写"不说：理由 __；代价 __"；与赌注无关的行写"—"。人物清单里每个人至少在一行说出口或写明不说的理由与代价。全场都不说出口时在表下写"本场不说出口：理由 __"。
- **删掉损失**每行必填：删掉这一行，观众少知道或少感到什么——写不出，这一行就不该在。
- **锚句** = 这次变化在正文里看得见的那一句（动作行或台词，逐字）；行按正文顺序排。**估时** = 从上一行锚句之后到本行锚句的台词秒数 + 无台词动作（越过、冲刺、过线、看一眼，每个都要时间）。
- 地点、活动、时间只写观众在哪里看见谁在做什么，**不写镜头、机位、景别**（那是 film-director 的事）。
- ≥30 s 的场少于两行有变化时，在表下写"本场静止：理由 __"（余韵戏、有意一镜到底、困住 / 对峙 / 等待的压迫感），并写观众在这段时间里看见处境怎么变；这是登记在案的例外，不是默认。
