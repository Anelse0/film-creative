# 情绪表演如何成为人物与故事

读完本页，再按需查 `emotion-index.md` 和 `../scripts/emotion_lookup.py`。25 条用户原文的独特价值在于身体反应的顺序、控制的变化和留存状态；它们没有提供角色目标、触发事件或剧情，因此不能直接等同于完整人物。这里补的都是创作推导。

## 保护原始证据

`../assets/emotion/prompts.json` 与 `../assets/emotion/mood_prompt.md` 字节原样保存；`../assets/emotion/provenance.json` 记录哈希。JSON 与 Markdown 的 25 个条目及全部字段已作交叉核对。原文件中的使用建议是材料内容，不替代当前用户要求。

原始 family / intensity / direction 保留，但不是心理学分类、测谎依据或模型效果结论。Crying、Eye Roll、Pain 等混合了情绪、行为与身体状态；不能由外观反推某个真人内心。剧本中的人物也可以被误读：低头不证明内疚，流泪不证明悔悟。

用户要求原文时返回所选原文，不顺手降强度、翻译或增加剧情。用户要改写时另标改编及来源 ID，原文继续不动。明确要求保持原动作顺序时逐项核对；只要求“参考其感觉”时可以做语义迁移，不必照搬每块肌肉。

## 从处境连接到反应

先在故事里认清：人物接到了什么，他如何理解，这影响了他什么眼前任务，他愿不愿被看出来。再选有用的条目特征，写出反应怎样延续到交流或行动。可以从动作先写起，再回查这些依据；无需每场填表。

反应有时立即发生，有时延迟，有时未被他人察觉。控制并非永远成功，也不一定要崩溃。只写本场真正有作用的通道与时间关系：呼吸早于笑、张口却没说、话说完脸才绷不住，或一段持续不释放的恐惧。不要每次都给眉毛、眼睛、下颌、肩膀与手各派一个动作。

## 独立调节，不整条缩放

| 判断维度 | 需要区分的内容 | 写作后果 |
|---|---|---|
| 内心强度 | 此事对人物有多重大 | 不直接决定音量和动作幅度 |
| 外显幅度 | 观众实际看见、听见多少 | 可从原条目取局部或另写合适的行为 |
| 控制动机与能力 | 为什么压住/放开，身体还能否维持 | 不把克制变成无变化；也不强迫失控 |
| 方向与对象 | 靠近谁、逃离什么、维护什么 | 同名情绪可长出完全不同的行动 |
| 时间与余波 | 触发、延迟、出现、持续、恢复、残留 | 顺序影响可信度；不配固定秒数 |
| 关系与观看 | 谁察觉，谁误解，观众知道多少 | 反应可改变话轮与后场，而不只是表情插图 |

原库 Explosive / Medium / Subtle 指原例外显形态。比如 #04 Rage 可在改编中成为高内心强度、高控制、低外显的愤怒；不是把咆哮动作全部写小。也允许保持完整爆发，不自动改得“高级克制”。

## 混合与变化

组合前先找新的触发或人物理解改变。一个条目不是一个必经台阶：#09 怀疑可以维持、被证实、被误导或转为歉意，并不必须走到 #03 恐惧。#23 宽慰可与 #20 内疚共存，行为有先后与主次，别同时写互斥的呼吸和嘴部动作。

同一条目可从不同人物任务长出差异；同一场也可无面部变化而通过工作、空间或说话方式表达。库外的嫉妒、悲喜交织等允许原创，标明“原创扩展”，不伪装成第26个原始条目。

## 可检索原文与推导

在技能目录运行，或使用脚本绝对路径：

```sh
python3 scripts/emotion_lookup.py --id 20 23 25
python3 scripts/emotion_lookup.py --query 假笑
python3 scripts/emotion_lookup.py --family Fear
python3 scripts/emotion_lookup.py --id 4 --raw
python3 scripts/emotion_lookup.py --verify
```

默认返回 original 和 derived_notes 两个独立字段。关键词检索是候选检索，不判断人物心理。无匹配返回空结果和明确提示；不自动替用户换成相近情绪。`--raw` 返回原始记录数组，prompt 字段逐字保留；JSON 序列化排版可以不同，原始文件字节保持不变。

## 原创迁移示例：同样的坏消息，不同的戏

**场景 A：有罪感并不等于自白。** 她接到“人找到了”的消息，先把那口气呼完。她本来要问伤势，却转问：“他提到我了吗？”对方停住。这里借 #23 的先释放后笑意的延迟机制（不强制笑），与 #20 的未能说出；反应进入新问题。是否有罪仍取决于剧本证据。

**场景 B：高强度的控制。** 他听到搭档把功劳全记给自己，继续报完设备数量；到对方要签字时，把自己那份从纸堆下抽出：“这一份你也签。”这是基于 #04 的控制与前推方向的改编，用持续任务与一次选择承载愤怒；并未声称逐字使用原表情。

**场景 C：允许完整快乐。** 多年没笑出声的姐姐被弟弟一个只有他们懂的动作逗得前仰后合，笑停后还扶着他的肩。他不忙着接台词，等她缓过来。可保留 #01 的爆发与余笑，不必用悲伤反转或羞耻打断它。

这些例子说明可迁移的决定，不供后续任务复用台词、道具与关系。实际成稿只选本作需要的行为，不展示整套参数。

## 写后检查

能指出反应的事件依据吗？人物是否依自己所知回应？控制与外显是否被混为一谈？情绪转移是否有新触发或理解？听者或后续行动是否受影响，还是只贴了表情？原文与改编是否清楚分开？强度和风格是否仍符合用户要求？缺陷用真实场景证据判断，不计算情绪条目数量。
