# 场景设计：先定这场戏怎么"转"，再写台词

S3c 写正文前的必需步骤：观众账本、核心一步三选一、设计卡。三样都短，写在剧本页的 `## 设计` 一节（模板 `templates/script-scene.md`），位置在事件轨和正文之前——先写下来的东西才会约束后面写出的正文。短于约 20 s、台词少于 4 句的过场可只写设计卡一行。

**为什么放在写之前。** 不设计直接写，第一稿会落在最常见的写法上：两个人站着，一个告诉另一个一件事，另一个回一句不表态的话。写完再查只能删句子、修措辞，修不了这种结构：
- 两个人互相说彼此都知道的事，警报应该一直响到这场被重新发明为止（McKee，S14）——改法是重建场，不是改句子。
- 按问题分类标出片段再重写，能改善措辞层的毛病；潜台词和结构问题逐句修改修不好，明确要求"避免陈词"也挡不住（Chakrabarty et al. 2025，`context-creativity-sources.md` §4.0.0）。
- 把转折点写进规划，悬念与张力明显提高（Tian et al. 2024，同上）。

## 一、观众账本：观众进场时已经知道什么

按 `story-context.md` 读前几场正文（台词、动作行、画面里看得见的字），列出与本场有关、观众**已经看到或听到**的事，每条一行、注出处；再列本场人物各自不知道的部分。

```
观众已知：
- A1 片方要把两人打包整个宣传期（前一场，经纪人电话）
- A2 对方只说了"考虑一下"（同上）
人物不知道：B 不知道 A1、A2
```

用法：
- **本场的事件不能只是"某人得知账本里的事"。** 人物得知观众已知的事，只有在**他得知的方式或他因此做的事**是新的时才值得演。否则晚进：场从他已经知道之后开始，只留他的反应、选择或反击。
- **同一条消息不平行送两遍。** 上一场 A 被告知，这一场 B 被同一条消息再告知一遍，是最常见的复述。B 这边要么直接从他的反应进场，要么让告知本身成为一次交锋：带消息的人要用它从 B 那里换到什么，B 不让。
- **观众比人物多知道的事要兑现**：人物按错误的认识行动，并付出代价或造成后果；只是"他晚一场才知道"不算兑现。
- **日期、时间、地点、流程**这类事实，全集完整说一次；之后交给画面（板上的字、手里的纸）或一句带过。同一场里反复报同一个时间，是在替观众做笔记。

## 二、核心一步：先写三种发生方式，再选

一句话写出本场要改变的那一件事：谁的什么，从什么变成什么。然后写三种**真正不同**的发生方式，每种一行——谁推动、用什么手段、在哪里做着什么：

```
核心一步：Theo 从"被安排"变成"自己定条件"
1. …
2. …
3. …
选 2：理由（谁得到或失去什么；观众在哪里被勾住）
```

- 第一种不能是"X 告诉 Y"。告知、宣布、转达可以作为第二或第三种出现，选它时写出它为什么仍是最好的。
- 至少一种让变化主要落在身体动作上，关掉声音也看得懂。
- 三种的差别在谁出手、怎么出手、谁付代价——不只是换地点、换道具。
- 用户要选时停下交三种；自主时自选一种，另两种留在页面上，不删。

依据：直接提示得到的往往是最典型的写法，先列出几种再选能拉开差异（Verbalized Sampling 2025，`context-creativity-sources.md` §4.0.0）；August 写场景的第 5 步也是问这场戏里最出人意料的事是什么（S13）。

## 三、设计卡：五格，每格一句

```
推动者与战术：谁想从谁那里拿到什么；用什么办法（逼、哄、换、拖、逗、示弱、亮底牌、装不在乎……）
阻力：谁或什么不让他轻易拿到；为什么此刻不让（对方的算盘、处境、时间、在场的人）
转折：推动者进场时以为会怎样 → 实际得到什么
弹药：哪条信息、哪个物件、哪件前事，被谁拿来当武器或筹码
静音测试：关掉声音，观众从动作与画面能看懂谁想要、谁赢了或输了吗；靠哪个动作
```

- **推动者**不一定是主角，也不一定赢。主角被推时，写出他自己的招：拖、反问、换条件、把球踢回去、当场拿走主动权。"被告知 → 回一句不表态的话"不是招。
- **阻力**来自有自己算盘的人，而不是作者的安排。Odets 改台词的检查（Mackendrick 转述，S15）：他说不出这句，因为对方不会让他这么轻易过关。
- **转折**是预期与结果之间的落差：场末处境与推动者进场时的预期不同——得到的比想要的少、多，或者是另一样东西。从头到尾价值没变的场是"非事件"（McKee，S14）。安静戏也有转折：想靠近的一步被允许，或被退回。
- **弹药**：信息只在有人拿它去赢的时候出现。没有人用它的信息，不进台词——放进画面，或删。
- **静音测试**不是要求少写台词，而是要求台词之外，身体在做的事与这场的输赢有关。好电影把对白换成听不懂的外语，观众仍能看懂六到八成（Mackendrick，S15）。换衣、吃饭、整理这类活动如果与输赢无关，只是背景；让活动被冲突改变——被人拿走、打断、拒绝、利用。

**不靠推动成立的段落**（余韵、纯观察、蒙太奇）写"本场不转：理由（观众这段在看什么）"。**靠近型**（`character-scene-development.md` §二）照填：推动者是想靠近的人，阻力是对方的犹豫或风险，转折是被允许或被退回。

## 四、写的时候：六条写法

1. **一个节拍 = 一次出招 + 一次回应。** 阻力逼出新战术，才进下一个节拍（Sorkin 的说法，August 转述，S16）；同一个战术换句话再说一遍不是新节拍。
2. **信息当弹药。** 人物说出一件事，是因为他要拿它换东西（McKee "convert exposition to ammunition"，S14；Odets 让每个走进对峙的人都带着弹药，S15）。互相交代双方都知道的事——那为什么还要说（Mazin，S17）？
3. **对手不配合。** 每个人都带着自己的算盘进场，不替对方递话。为了让观众听到信息而让人物装糊涂追问一句，等于削弱人物（Mazin，S17）。
4. **人物主动。** 被动是戏剧的死罪（Mackendrick，S15）；被推着走的人也在选择——拖延、讨价、反将一军，或者选择不说并付出代价（`story-engine.md` §四 三问）。
5. **演处境，不演台词。** 同样的台词换一个好看的背景，不会因此更像电影（Mackendrick 称之为"opening it out"的谬误，S15）；要变的是人在做的事。给处境施加身体压力——Odets 对演员说别让人物舒服地坐下。
6. **晚进早出。** 场从事情已经在发生时开始，不从寒暄、走路、落座写起；结果一出来就走，不写走出去的路（Mazin：看人走路是"shoe leather"，S18）。

日期、流程、制度这类必须交代的内容，按 `character-scene-development.md` §五"解释制度或工作"一行判断：听者需要知道才说，并且放进某人要东西的那一句里。

## 五、误用信号（两个方向都有）

- 为了"有推动者"把每场写成争吵：靠近、合作、余韵照样成立，推动与阻力可以很轻。
- 为了"弹药"加秘密、反转、新设定：弹药优先从前文已有的事里找（`story-engine.md` §一：不靠加秘密、反派、事故续命）。
- 三种发生方式只是换地点、换道具，谁出手、谁付代价没变。
- 静音测试被读成"少写台词"：已锁定的台词不因此删，台词与动作同时承载。
- 为了"动作承载"强加道具或走位：动作要与输赢有关，不是装饰。
- 设计卡写得漂亮，正文没兑现：卡上的战术与转折要在正文里看得见；事件轨的锚句由脚本逐字核对，设计卡的兑现由作者自检，需要时交冷读（`cold-read.md`）。
- 用户指定了传话安排（"经纪人转达片方的事"），就写转达——但转达的人有自己的算盘，消息遇到抵抗或被拿去交换；不擅自改成别的事件。
