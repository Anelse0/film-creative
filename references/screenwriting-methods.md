# 编剧方法落地：按问题选，不按地域套

好莱坞与韩国创作者的一手实践用于扩展工具，不定义两种固定美学。以下步骤是本 Skill 的提炼，**不是原作者的逐字教程，也不是必须走完的流程**。出处、访问范围及局限见 `context-creativity-sources.md` 中同编号来源。

先按 `story-context.md` 确定相关事实、当前状态和允许改动。只选对当前问题有用的方法，实际写出正文；已有好稿直接保留。短任务不要求解释方法名称，更不在输出里摆满七张卡。

## H1 场景既有全片作用，也有当下看点

启发：John August 的场景写作步骤。

- **用于**：一场单看热闹却不属于本片，或只为传递信息的过桥戏。
- **做法**：从整体找本场不可丢的作用（也可以是关系积累或余韵）；把“需要交代什么”改成角色当下正在处理的事情。卡住时，在同一进场状态与出场边界内试不同进入点，写实际开头/连续段，不只列地点。选出既接得上前文又让人愿意看的写法，接读后场。
- **产出**：有具体交流/行动的场景；必要时一句说明新增看点落在哪里。
- **失效信号**：为了意外改写硬锁；删掉所有不推动主线的观察段；把“多试入口”变成每场固定配额。

## H2 从每个人的处境理解选择

启发：Tony Gilroy 论行为复杂性、共情与研究。

- **用于**：配角只为刁难主角存在，人物突然坦白、发疯或降智，职业只剩标签。
- **做法**：暂时从另一人的位置读同一场：他实际知道什么、要保住什么、认为自己在做什么合理的事？取已有材料里一项足以改变选择的生活/工作条件；真缺事实才研究。让双方各自的可理解选择相遇，写出尝试与回应，再看谁承担了代价。
- **产出**：动机体现在行动和对白里；无需为每个配角写背景小传。
- **失效信号**：理解变成替伤害开脱；编童年创伤替任何行为辩护；用主题立场代替对方此刻的实际需求。

## H3 让前一次选择改变下一次选择

启发：Craig Mazin 的人物与核心戏剧论题关系。

- **用于**：中段流水账、角色每场重来、结尾只用金句宣布成长。
- **做法**：从已写行为找出人物目前相信的做事方式，不先替全片写格言。让一个已有问题暴露该方式的收益与代价；把所得、所失或认识带到下次实际选择。结尾用选择及后果回应开头，人物也可以坚持原路并承担后果。
- **产出**：跨场可连续阅读的故事，读者能指出哪里使后来的行动改变；复杂时在原故事注释记受影响场次。
- **失效信号**：按页码制造灾祸；每人必须改正缺点；把观察性、平行或拒绝成长的故事改成价值说教。

## K1 让空间和日常条件参与因果

启发：奉俊昊谈《寄生虫》的空间编排、生活细节与人物处境。

- **用于**：偷听/隐藏/相遇靠巧合，场景只有地点名称，社会处境只靠人物发表观点。
- **做法**：从既有空间确认谁能进入、看见、听见、离开，谁能支配什么；从真实或明确虚构的日常条件找一项不对等，写它如何限制当下行动。同一动作对两个人造成不同后果，就能生出戏。需要改布局时先查是否开放，已锁定的门窗、距离和资源不能为高潮突然失效。
- **产出**：正文中的视听依据、行动路径及其后果；只写影响剧情的空间信息，不画分镜。
- **失效信号**：照搬豪宅/地下室/阶层符号；无依据隔音或穿墙听见；用“底层/富人”标签解释一切；为了装细节加入无关道具。

## K2 用同一件事承载两种牵引

启发：朴赞郁谈人物在感情与职业责任之间的拉扯；郑瑞景谈调查过程如何成为理解对方的过程。

- **用于**：类型事件与人物感情各写一场，彼此没有影响；人物一谈感情就停止办事。
- **做法**：找正在进行的实际任务，再找关系中的另一种牵引。写一个既推进任务又改变亲近/信任/权力的选择；检验其中一面是否让另一面付出具体代价。关系可以是师徒、家人、同事，不必爱情。任务细节继续遵守事实和角色权限，不能以心动解释一切违常行为。
- **产出**：一段同时能读出事件进展与关系变化的正文，之后两方面的后果都要带下去。
- **失效信号**：照搬警探爱上嫌疑人；用类型混搭标签替代事件；为了关系戏突然废掉职业能力、规则或前场承诺。

## K3 人物措辞有来处，听者理解有过程

启发：郑瑞景谈《分手的决心》里角色的语言来源与非母语表达。

- **用于**：所有人同一腔调，文气被一律删掉，或人物为了观众而互相解释背景。
- **做法**：核对这个人从哪里学会这种说法、面对谁、当下想让对方明白什么。若措辞让听者理解偏移，写出对方实际怎么接、说者如何处理；误差必须在语境中成立。可保留直说、完整句和文学性，不用语气词/断句制造假口语。
- **产出**：可连续听懂的对话片段；陌生措辞服务角色关系与事件，不只充当漂亮句子。
- **失效信号**：由国籍/职业自动分配口音或词库；捏造语言障碍；移植原片台词；每句都做双关，或让误会毫无后果地反复出现。

## K4 留住不确定性，同时给行动以依据

启发：李沧东谈《燃烧》的不确定性与角色内在动机。

- **用于**：悬念只能靠藏信息，或 Agent 为“逻辑完整”擅自揭晓用户要保留的谜团。
- **做法**：分清已发生事实、人物猜测、观众可能解释。保留必要的可见证据，让不同理解有真实依据；人物依自己的理解采取行动，并产生可观察后果。写完查是否把一种猜测偷偷写成叙述事实，或为了两可而抹掉行动理由。未知真相可以保持未知，不必由 Agent 私下编一个标准答案。
- **产出**：读者能说清人物为何这样做，同时仍可对未定事实保留不同判断的场景。
- **失效信号**：什么都不交代；人物随机行动；谜团的多解以违反已定事实为代价；把所有类型强改为开放结局。

## 采用后的共同步骤

只比较正文中的收益、所需新前提和受影响后文。新段若精彩却越界，先改回边界内，或仅作为明确的上游修订提案；不能靠“作者风格”豁免连续性。采用后按 `story-context.md` 更新状态变化，按 `creative-loop.md` 保留改稿优点。
