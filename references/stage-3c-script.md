# S3c 剧本落地

输入：故事正文、已有完整场景或有效探索片段，以及相关用户硬锁；场景清单与两侧问题是可选辅助。输出完整剧本页，范围、停靠与保存按 `execution-contract.md`；需要保存时写 `03_script/scene-XX.md`。

剧本页是 A 层 + B 层：允许抽象的只有"导演意图"一栏；动作行与台词从这里开始就必须可拍。

共用方法：`character-scene-development.md` §四 人物声音、§五 对白审阅 · `causal-chain.md` · `creative-loop.md`（重写）· `research-to-craft.md`（行为与台词缺口）。

## 3c.0a 开写前的故事依据（约束）

先按 `story-context.md` 读取本场所依赖的整体故事、相关前后场和远处铺垫，提取进场状态、知识边界与后文仍须成立的事实。独立单场只核已有处境，不要求完整全剧；加戏也不自动扩展改稿范围。需要新意时按 `creative-search.md` 试人物选择和后果，不能凭空加设定替场景制造高潮。

这些依据是**约束**：正文不能与之矛盾。它们不是本场台词的清单——"后文仍须成立"写了三件事，不等于三句台词各还一件。

## 3c.0b 事件轨（写台词和正文前的必需产物：谁要什么，每一行变了什么）

有对话的场景、或估时 ≥30 s 的场（含无台词场），写第一句台词前先填剧本页模板的"事件轨"（`templates/script-scene.md`）。3.7.0 起它合并了原来的"本场赌注"卡（3.5.0）与"场面轨"（3.6.0）：两张卡分开时，地点换了就算画面推进，不说话的人又不在赌注卡上，于是一段没有事件的无台词新地点能同时通过两项检查（EP03 场 4 v4.1"几分钟后，牛棚边"，见 §3c.8）。合成一张后，**每行是一次变化，地点、活动、时间只是这次变化的属性**。

**人物清单**（表上方，每人一行）：本场说 ≥3 句的人，以及任何一行变化的主体——**不说话的人也在内**（牛棚里蹲着的捕手要上清单，就得写出他这一季要什么、此刻向谁要什么）。
- **持续赌注（出处）**：他这一季 / 这一阶段能得到或失去的具体东西（名单、先发、奖学金、家里、工作、关系），从 `ip.md`、故事正文或分集框架里找，写明出处；找不到就是人物缺口，回 `stage-3b-story.md` §3b.3c "想要"格补，不在本场临时编。
- **此刻向谁要什么 / 怕什么 / 为什么是现在**：Mamet 三问（`dialogue-review-sources.md` S6）落到这一场、这个对象。

**行**（按正文顺序）：
- **谁 → 对谁**，**变化：进 → 出（类别）**——谁的什么状态变了（得到 / 没得到 / 推迟 / 失去 / 信息 / 关系 / 决定 / 物件 / 地位；"观众"也可以是主体，只改变观众所知）。进出相同、或与同一人前面某行的"出"相同，都不是变化。"推迟 / 没得到"写代价：被一句"That's fair / Okay"接住就收掉的欲望，代价写不出来。
- **说出口**：这一行里"谁"会说出口的那句，逐字写下；或者"不说：理由 __；代价 __"（`character-scene-development.md` §一 隐瞒三问）。清单上每个人至少在一行说出口或写明不说的理由与代价——包括不说话的人。
- **删掉损失**：删掉这一行，观众少知道或少感到什么（删除测试，取向 5 落到行一级）。写不出就删这一行或并进上一行。
- **地点（子空间）/ 活动 / 时间 / 锚句 / 估时**：见下。

**优先级**：台词先分给清单上的欲望，再核 3c.0a 的约束。承接与埋点能放进动作行就放进动作行；必须由台词交代的，夹进某人要东西的那句里（他为了要到什么才提起它），不单独占一句"回收上一场"。取向 6 与 §五 里的"不替人物总结主题""不解释""克制"管的是欲望**怎么说**，不管**说不说**。

**地点是属性，不是推进**。剧本层写观众在哪里看见谁在做什么——地点与子空间、活动、谁进出、时间跳；用什么镜头、机位、景别、运动、切点去看属于 film-director，写到"侧跟拍 / 近景 / 反打"就越界了。**先问地点**（John August 第 4 步 "Where could the scene take place?"——最显而易见的地点通常最无趣；`dialogue-review-sources.md` S13）：这场戏放在哪里、人物在那里做什么，才让这一行的变化有看得见的处境？再问第 6 步"这场长还是短"。但地点只能**承载**变化，不能**代替**变化：
- 一行换了地点或跳了时间，这一行就必须有变化；没有变化只让观众"换个地方看看"的行不成立。
- **余韵**（没有变化、让刚发生的结果停一下）写"无（余韵：理由）"：可以留，不算推进，只能在原地、不跳时间（"队伍跑进太阳"是余韵；"几分钟后，牛棚边"不是）。余韵合计超过约 10 s 时复核——交给分镜时它最容易被扩成一整条 clip。
- 全场一个地点、一种活动**不是问题**：只要行行有变化（EP03 场 4 v4 整场跑道，9 次变化）。review 会列一条复核：这些变化观众看得见，还是都在台词里——这是 §3c.0c 的诊断入口，不是换景的理由。

**变化太少**：估时 ≥30 s 的场少于两行有变化时，要么补上真正的变化，要么在表下登记"本场静止：理由"（余韵戏、有意一镜到底、困住 / 对峙 / 等待的压迫感），并写观众在这段时间里看见处境怎么变。观众等一次变化等了约 40 s 以上的行列复核（有意的压迫，还是中间缺一次变化）。全场都有理由不说出口时，登记"本场不说出口：理由"（如余韵戏、赌注已在上一场说尽）。这些都是登记在案的例外，不是默认。

**估时**：每行 = 从上一行锚句之后到本行锚句的台词秒数（词数 ÷ 语速；THE ORDER 用 4 词/秒）+ 无台词动作。越过、冲刺、过线、看一眼、换到新地点，每一个都要时间，不能被压进台词里；台词之间一两句的反应可与台词同步。总估时写在表下，节拍表不另估。`review_script.py` 按同一方法独立估一遍（`[推论]`，5 场校准误差约 ±15%），自报明显偏小时列复核。

**脚本能查什么、不能查什么**：`review_script.py` 逐字核对锚句与说出口的句子、比较同一人的前后状态、找出"换了地点 / 跳了时间却没有变化"的行、变化主体不在清单里的行；写得出变化的行一律通过脚本。变化是不是**新的**（前面几行是不是已经给过）、删掉观众到底损失什么，脚本判不了：换地点 / 跳时间 / 较长的无台词行 / 只改变观众所知的行，review 会列出它的变化、删掉损失、同一人上一次的状态、同一对象上一次被怎样对待，交模型按删除测试复核，结论写进同一份 review。

交给 film-director 时，事件轨是**告知**（本场有哪些场地 / 场景、每行发生什么变化、大致多长；余韵行标明是余韵），不是锁定：分镜可以重分段、换子空间、换活动或地点，在方案里写明差异；分镜时长超出事件轨总估时 20% 以上只作提醒，回不回剧本层由用户定。事件轨是写作依据，不是交付正文：落盘时放在剧本页之前，对话内交付时放在剧本页之后，按需简短回显。短于 30 s、台词少于 4 句的过场可不填。

## 3c.0c "这场画面单调 / 整场都在一个地方"：先诊断缺什么，再谈换景

用户对画面的疑问（"整个场 4 都是球场跑步吗？""这场画面没变化"）是**症状**，不是改法。3.6 把它直接路由成"换不换景"，于是改法选项里只有换地点，加出来的牛棚段 16 s 没有事件（用户："这 16 s 存在的意义是？"）。先用事件轨回答缺的是哪一种：

| 诊断（看事件轨） | 缺什么 | 改法方向 |
|---|---|---|
| 有一长段没有变化的行，或 ≥30 s 只有 ≤1 次变化 | **事件** | 在原地补一次真正的变化（谁得到 / 失去 / 知道 / 决定了什么）；或压短、删掉那段 |
| 变化都在台词里：人物在做的事与赌注无关（边跑边谈、边吃边谈），观众看见的动作不改变任何人的处境 | **人**（能把赌注做出来的动作或在场的人） | 让赌注落到当场的动作或一个进出画面的人（有人看见、有人离开、有人被叫到前面）；动作可以换，地点可以不换 |
| 观众这几十秒新知道的东西都靠嘴说，或前面几行已经给过 | **信息** | 让观众看见一件前面没给过的事（物件、结果、第三人的反应）；已给过的删掉 |
| 行行有变化、看得见，只是一个地点一种活动拍久了单调 | **都不缺**，是生产侧问题 | 剧本不加段；交 film-director 在分镜里处理（事件轨是告知不锁定），可在交接说明里写一行 |

诊断之后按 `execution-contract.md` §修改请求 给改法：解法不止一种时交两到三种选项，**每个加段或换景的选项都要写出新行本身**（谁：进 → 出、删掉损失）——写不出变化的换景不列为选项。"删掉 / 压短"和"不改剧本、交生产侧"都是合法选项。换景只是承载变化的手段。

校准：EP03 场 4 v4（整场跑道，9 次变化）诊断为"都不缺"，或最多"变化都在台词里"；v4.1 加的牛棚段按 v4.1 自己的卡回填是余韵——Isa 场末仍是"推迟"，只在后面接了"Diego 在牛棚里蹲着等他，他还坐着"这个画面——换了地点、跳了时间，没有人得到或失去什么；v4.1 删掉牛棚段是对照，事件轨通过（`tests/fixtures/review/theorder-ep03-s04-v4*-events.md`）。

## 3c.1 一场戏的问题

人物侧：谁要什么、为什么是现在（已在 3c.0b 人物清单上）· 什么挡着或什么在靠近 · 他怎么试 · 每一行什么变了（得失 / 关系 / 信息 / 物件归属 / 地位 / 决定；已在 3c.0b 的行上）。
观众侧：进场时知道什么、期待什么 · 哪个证据改变他们对人物的判断 · 他们看见的变化在哪里发生（已在 3c.0b 事件轨上）。
从故事正文与已有场景中理解两侧；已有清单可以沿用，缺表不补表。授权修订可以回写故事。

## 3c.2 节拍表（需要展开交流节拍时，正文后补；估时在 3c.0b 事件轨）

剧情节拍按实际尝试与结果划分，数量由内容和时长决定。可用"尝试 → 受阻 → 调整 → 代价"检查；靠近型场景用"试探 → 允许 / 退回 → 代价"；纯表演测试跳过本阶段。

```
| # | 谁对谁 | 本段交流或行动（策略按需） | 阻力或回应 | 结果或持续状态 | 观众此刻知道 | 落差（若有） | 估时 s |
```

节拍按交流划分（尝试与回应），事件轨按变化划分（谁的什么变了），二者粒度常不同；估时统一写在事件轨（台词 + 无台词动作），节拍表的估时列可选，填了须与事件轨一致。估时标明同步与先后；不用平均节拍时长决定镜头。策略列的动词服务演员与分镜，不是台词成立的判据。

## 3c.3 空间即戏剧

按场景需要明确入口/出口、起止位置、相关物件、光与声音。空间是类别名（"医院走廊"）时按 `research-to-craft.md` 补实际陈设与动线。人物关系可以通过距离或表演变化呈现，不强制走位或每场一个道具。每一行变化在哪里发生（地点、子空间、活动、时间跳）在 3c.0b 事件轨，这里只管空间本身与连续性。

影响本场事件或连续性的物件，追踪初态、实际转移与末态：谁拿、在哪、是否开合、由哪个动作改变。写在现有空间/节拍字段，不为所有陈设建表。人物对白可含歧义，动作行里的“她/它/这边”则要能定位；一块布从灯旁到灯下须有转移，不能在 C/D 两层复制同一个遗漏便称保真。

空间承担隐藏、偷听或关系压力时，可按 `screenwriting-methods.md` K1 检查人物可见/可闻/可达的范围。不把剧本开发变成分镜设计：写"观众在哪里看见什么"，不写"用什么镜头看"。

## 3c.4a 从有效入口开发，再检查

可从场景梗概、事件、人物或对白草稿进入。先有一句可信的话也可以；不要先给每句分派策略再让人物填空。依据 `character-scene-development.md` 补确有缺口的交流处境，写出连续片段后审阅。逻辑断裂处再用 `causal-chain.md` 追查，不要求逐句建链。新发现回流故事，不能覆盖用户锁定内容。

## 3c.4 剧本页格式

```
场 XX 〈标题〉 · 地点 · 时刻
动作行：写清人物在场内做什么及可见可听的结果，读者能连续理解。情绪名称不能替代具体证据；保留速度、幅度和渐变信息。
角色名
    台词。
    （括号补实际有用的表演/声音提示，锁定台词不因格式被改字）
动作行：…
```

先写可连续阅读的正文，再补必要生产注释；部位级执行组织仍由 S4 承担，不把 C 层语法提前用作每行动作的写作模板。用户提供或锁定的表演正文完整承接。

动作行应让所选表演可见，例如“她看着他，眼泪积在下眼睑，抬眼忍住”。这只是新编示意；具体通道依场景或原库选定，不因原句抽象便擅加杯子、递物或固定两秒停顿。

## 3c.5 台词

### 场景与交流诊断

统一读 `character-scene-development.md` §四–五。按连续交流片段审阅人物知道什么、为什么此刻这样说、对方如何接收；不要求每句留下上一句的词、不要求每句执行一个及物动词。直接回答、回到早先话题、完整长句和有意重复均可成立——前提是它们带来了东西（见下节）。发现问题才定位到具体句子，不把诊断问题变成生成配额。

当任务与感情分成互不影响的两段时用 `screenwriting-methods.md` K2；人物措辞缺来处时用 K3；要保留多解但行动失去依据时用 K4。只写当前所需正文，不堆叠手法。

### 删除测试与压缩测试（写完连续片段后、交付前；3.8.0）

"接住上一句"只保证不是交错独白，不保证每句有用。真实会话里的接话、确认、复述，屏幕上要压掉：观众听过一次的不再听第二次，重复的台词要删，uh-huh / yeah 这类接话在剧本里很少，不是每一句该说的都要写进对白（Scriptnotes 609，`dialogue-review-sources.md` S5）。写完一段连续对白，交付前做两步，直接改自己的稿（这是写作步骤；审阅用户的稿时只提改法，不改稿）：

1. **删除测试（逐句）**：删掉这句——必要时连同只为回应它而存在的下一句——观众少知道什么、少感到什么？答得出（信息 / 要或拒 / 关系的变化 / 笑点或性格 / 必要的调度 / 后文要回扣的铺垫）就留；答不出就删，或并进下一句、并进一个动作。观众已知的范围按**真实剧情**算：前几场的台词（`story-context.md` 指认的前文，review 时 `--context`）、本场前面说过的、画面刚给的（动作行里已经演了的事，台词不再报一遍）；同时看后几场（`--later`）：一句看似多余的话若在后文被回扣（"I'll be back before half past" → 场 3 蜡烛烧化），它是铺垫，先确认再动。
2. **压缩测试（逐段）**：一段来回先写出"这段要改变的一件事"，再问最少几句能做到。**简单的事不要复杂化**——一个事实、一个决定、一个邀请，用几轮确认、复述、反问摊开，就是啰嗦；长句、完整句本身不是问题。来回多可以成立，条件是每一回合都有人的立场或压力在变（讨价还价：Mack 用时间拦、Lena 压回五分钟；调情：否认 → 被当场抓住 → 认输）；复述、确认、递话问句不是在变。

记录写在剧本页"对白审阅"下的 `### 删除测试`（模板见 `templates/script-scene.md`）：`删：「逐字原句」——理由`（已删掉的句子，正文里不应再有）、`并：「原句」→ 并进哪里`、`压缩：「首句」…「末句」N 句 → M 句；这段要改变的一件事`、`留：「原句」——它带来什么`（脚本候选里判为有作用的）；什么都没删写 `删：无`。`review_script.py` 核对这份记录与正文是否一致，并把没被记录覆盖的候选（接话 / 重复 / 递话问句 / 截断）与低信息段附上"前文哪里说过 / 后文哪里回扣"列为复核——候选只是线索：按 10 场盲评标注，表面规则的精确率约 0.34，讨价还价、回扣、嘴硬、调情都长得像接话。

误用信号：为了省字删掉讨价还价、回扣、调情的节奏；把一句带立场的短句（"Lena." / "Five."）当接话删；为了"每句有信息"把台词写成交代；把回应全换成沉默。

### 参数关（由场景参数卡决定，见 `scene-parameters.md` §二）
句长、直接表达、停顿、打断与结尾由场景、角色声音和可用时间决定；场景参数不是固定配额。既有台词锁定，仅在用户要求修改时改写。

### 对白审阅（写完整场之后）
剧本页落盘后先跑 `python3 scripts/review_script.py 03_script/scene-XX.md --context <前几场> --later <后几场>`（多场可一次传入；`--json` 给逐句特征；`--wps` / `--action-sec` 调估时参数）。3.8.0 起总判断另报**台词经济**：缺删除测试记录（只在总判断里报一句）、记录与正文不符判为问题；候选与低信息段附前文出处、后文回扣列复核，由模型按删除测试 / 压缩测试定，不按候选多少定问题；总判断不再报"有人接的台词占比""最长来回轮数"，也不再输出"全场没有一个问句"——它们把接话和问句当成越多越好。其余两项：**事件轨**（3.7.0 起合并人物赌注与画面推进）——人物清单齐不齐（说 ≥3 句的人与每个变化主体，含不说话的人）；锚句与说出口的句子逐字在正文、顺序一致、本人说、有没有人接；不说的有没有理由与代价；进出相同、同一人的"出"重演、换了地点或跳了时间却没有变化、≥30 s 少于两次变化且未登记"本场静止：理由"、缺事件轨，判为问题；换地点 / 跳时间 / 较长无台词 / 只改变观众所知的行附证据交模型做删除测试，全场一个地点、余韵合计 ≥10 s、观众等一次变化 ≥40 s、自报估时比文本估时小 15% 以上列需模型复核——与**对白连通**；"对白连通通过"不代表这场人物有戏。连通部分脚本只算可量化项——每句有没有收件人、下一句接不接、两人来回的轮数、句长与无理由短句占比、主谓宾完整度（英文）、画外标注、换到第三人且不接前句的比例——潜台词支点（省略句里当作已知的设定前文有没有建立；用 `--context` 传入 `story-context.md` 指认的前几场）——并把收件人不明、能否同框、"是旧梗还是观众需要的设定"列为"需模型复核"。潜台词无支点时脚本附三种改法（直说来历 / 用当场动作引出 / 让在场的人带着自己的立场问——不是替观众递一句"What X?"，各含"改什么 / 这场变成什么 / 影响后面什么"），按 `execution-contract.md` §修改请求 作为改法未定时的选项，不改稿。模型按取向 6（面对谁、刚发生了什么、为什么此刻、说完对方怎么接）复核这些句子，把结论写进同一份 review，按 `SKILL.md` §默认输出契约的诊断格式交付。脚本不改稿，判为通过只表示没触发已知问题；每条判断的一手来源与 `[推论]` 阈值在 `references/dialogue-review-sources.md`。对话内未落盘的剧本页可先存到临时文件再跑。
按共用方法检查交流依据、人物声音与可说性。记录有文本证据的问题、保留项和修订代价；不凭“无问题”三字宣布质量通过，也不因全句工整或双方都激动而自动改写。遇到刻意编排，按 `character-scene-development.md` §五"刻意编排"表找实际原因：场景前提、信息依据、听见了什么、关系与处境、人物是否真会这样说；对白问题不一律用改台词解决。

### 执行信息与空泛描述
- 动作行保留可观察的速度、程度、渐变、持续与控制，不因"逐渐""缓慢"等词而删细节。
- 情绪标签不能代替表演；音量、语速放在"说法"栏。
- 台词自然度由角色与场景审阅，不计副词配额。下表用于决定是否需要补信息，不提供一键替换句式。

| 原句 | 信息作用 | 处理依据 |
|---|---|---|
| "她冷冷地说：随便。" | 态度概括 | 台词保留；需要执行时明确本场已有依据的音量、视线或发声方式，不自动加道具 |
| "他真的真的很想她。" | 内心或对白 | 内心留 A 层；若是台词，重复可能有效，不能机械删字 |
| "他愤怒地摔门。" | 情绪加动作 | 摔门已可见；按场景补力度或结果，不能无依据加灰尘 |
| "她小心翼翼地问……" | 交流态度 | 判断顾虑是什么、对谁说；不强加停顿或“对吧” |
| "他慢慢地走过去。" | 可观察速度 | 保留速度，确需计时时估算距离和时间，不统一改成三秒 |

### 张力六源（可选武器，不是配额）
想说不能说 · 权力转移 · 打断 · 重复变义（回声） · 用动作回答 · 沉默作为台词。参数卡与叙事方式决定哪几源是主武器。

### 每句四件套（需要时）
台词（逐字引号）· 潜台词（A 层）· 说法（音量 / 语速 / 停顿位置 / 说完看哪，写可观察量）· 听者（视线 / 手 / 身体）。30 秒任务或台词很少时可只对关键句写。

## 3c.5b 任务范围提醒

- **优化单集**：先按 `episode-design.md` §一 答承接 / 进入 / 兑现 / 牵引，再写分场；已定结尾与前后集事实不动。
- **只优化对白**：交付只改对白的整段全文；事件、人物设定、场景、结尾不动，不顺手加道具、前史或新事件；说明改了哪几句、为什么（`character-scene-development.md` §五）。范围小不等于改得少：改后每个人都有此刻说这句的理由，两人的声音读得出差别；一方明确表态、另一方让步可以成立，只要各自的理由和口吻是自己的；保留原稿里有效的句子。
- **只诊断**：不交新版本；交付格式统一见 `SKILL.md` §默认输出契约（一句总判断 + 最多三个独立问题，默认约 500 字、最多 800 字）。

## 3c.6 停靠交付（对话内）

每场先交付剧本页全文，生产参数、空间核对与估时说明放在正文后，按需省略。多场交付前做 §3c.6a 连读。下一步只在用户目标范围内推进，实际需要选择才提问。

按 `execution-contract.md` 的保存约定写 `03_script/scene-XX.md`。台词体检（用户已有剧本）：不重写，按共用诊断给出具体证据、可能原因与不确定处；修改需用户要求。

## 3c.6a 整场与整片连读

局部改写也按 `story-context.md` 接读相关前文、新场、受影响后文与远处铺垫，避免提前兑现后场。采用后只记录状态变化和实际依赖；未授权修改的后场列待复核。

从第一句到最后一个事件，按实际呈现顺序只读正文：前场留下的处境能否带入后场，信息是否重复或缺失，人物、物件与声音能否连续，台词、动作与必要停留能否容纳在总时长内；把各场事件轨的最后一行与下一场的第一行连起来看，连续几场是不是同一种画面、同一种变化。同步动作不重复相加，不能因拆成多个 clip 就声称总时长成立。记下具体断点与估时假设后定点处理；这是文本模拟，不是真人排练或生成效果验证。

保存的多场剧本可用 `scripts/assemble_script.py` 按指定顺序汇集正文到 `03_script/reading.md`。这是派生视图，修改仍回各场当前稿；以源文件哈希记录依赖，上游改变后重新汇集，不能反向覆盖场景。没有保存授权时在对话内连读，不创建文件。

## 3c.7 重写

收到批评后按 `creative-loop.md` §二诊断层级并判改法：改法未定且解法不止一种时先给改法选项，不改稿；改法已定后按 §三执行：保留上一版、说明改了什么与解决什么、核对失去的细节、定点改、不换故事。**未被批评的场景设定保留，但改完内容量或估时变了 ≥20% 时，重做事件轨**，在修订账本"事件轨重核"栏写结论：每行还有变化吗、旧地点与活动还装得下吗（EP03 场 4 v4 只换台词，从 61 词到 142 词、估时从 47 s 到 57 s，场景原样保留）。装不下或画面单调时，先按 §3c.0c 诊断缺什么，再按 §修改请求给选项；换景只是其中一种，且要写得出新行的变化。改稿是探索稿，采用前不同步故事、框架、正典。示例见该文件 §四。

## 3c.8 常见失败

| 现象 | 处理 |
|---|---|
| 转折只靠一句宣布，缺乏可信依据 | 先查人物为什么改变；直接说出决定可以成立，不自动换成放钥匙 |
| 只有情绪形容，没有可见表现 | 补可观察证据；不按"地"或词性判错 |
| 对视没有戏 | 检查持续压力、变化与目标，有意凝视不强配道具 |
| 台词像同一个人写的 | 查语言经历、交流对象与当前处境；共用日常短句不机械重写，不分配口头禅配额 |
| 场景只为宣布主题而存在 | 重审这场戏发生的理由，不只把宣言口语化（`character-scene-development.md` §五） |
| 台词都在处理剧情账：回收上一场、给后集埋点、交代流程，没有一个人说出自己要什么 | 回 3c.0b：先填人物清单，台词先分给欲望；承接进动作行或夹进欲望句（THE ORDER EP03 场 4 v3，用户 2026-09-23 否决"平铺说话"） |
| 场景只写了地点：标题、注释、空间都有，整场观众看见的却是同一个画面，分镜只能靠机位轮换补 | 回 3c.0b 填事件轨，看每行有没有变化；再按 3c.0c 诊断缺的是事件、人、信息，还是都不缺（交分镜）。不因"只有一个地点"就换景（THE ORDER EP03 场 4 v4 整场跑道但有 9 次变化；用户 2026-09-23 问"整个场 4 都是球场跑步吗？"） |
| 为了"画面不一样"加一段新地点或空镜：没有人得到或失去什么，场末与进场一样，删掉观众什么也不少 | 这一行在事件轨里写不出变化——删掉，或在原地补一次真正的变化；余韵只能在原地（EP03 场 4 v4.1"几分钟后，牛棚边"：Diego 蹲着等、Beckett 按一下肩、Isa 还坐着，Isa 不答已演过两次；导演侧排成 16 s 整条 clip，用户 2026-09-23："这 16 s 存在的意义是？"） |
| 对白里一件简单的事被拆成几轮：确认、复述、"Okay / I know / That's what I said"、答案下一句就给的递话问句；观众在前场或画面里已经知道的又说一遍 | 3c.5 删除测试与压缩测试：先写这段要改变的一件事，按最少句数写；每一回合要有人的立场或压力在变，否则删或并进动作；对照前后场（`--context` / `--later`），后文回扣的先确认是不是铺垫（用户 2026-09-24："对白连通目前存在设计废话的问题"；盲评 THE ORDER / reckless 10 场 219 句，34 句纯接话） |
| 结尾总是一句金句 | 判断人物是否真会这样说；允许直说，也允许不总结 |
| 疑似交错独白 | 查连续片段的回应依据；延迟回应、各执一词也可有意成立，不以句子能换位单独判错 |
| 需求明确要喊出来，却写成沉默对峙 | 具体表达方向被默认覆盖；按需求修正 |
| 每项特征都在，但交流不成立 | 回交流处境查作者安排是否越过人物所知；必要时追查因果 |
| 人物解释制度或工作 | 看听者是否需要知道、人物为何此刻解释；不把合理说明一律当科普删除 |
| 事件超出 30 秒承载 | 保留核心因果与高光，重排同步/先后；不足时在授权内减量或说明时长冲突；拆 clip 不能增加总时长 |
| 重写后原稿的有效细节没了 | `creative-loop.md` §三 第 3 条 |
