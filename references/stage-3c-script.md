# S3c 剧本落地

输入：故事正文、已有完整场景或有效探索片段，以及相关用户硬锁；场景清单与两侧问题是可选辅助。输出完整剧本页，范围、停靠与保存按 `execution-contract.md`；需要保存时写 `03_script/scene-XX.md`。

剧本页是 A 层 + B 层：允许抽象的只有"导演意图"一栏；动作行与台词从这里开始就必须可拍。

共用方法：`character-scene-development.md` §四 人物声音、§五 对白审阅 · `causal-chain.md` · `creative-loop.md`（重写）· `research-to-craft.md`（行为与台词缺口）。

## 3c.0a 开写前的故事依据（约束）

先按 `story-context.md` 读取本场所依赖的整体故事、相关前后场和远处铺垫，提取进场状态、知识边界与后文仍须成立的事实。独立单场只核已有处境，不要求完整全剧；加戏也不自动扩展改稿范围。需要新意时按 `creative-search.md` 试人物选择和后果，不能凭空加设定替场景制造高潮。

这些依据是**约束**：正文不能与之矛盾。它们不是本场台词的清单——"后文仍须成立"写了三件事，不等于三句台词各还一件。

## 3c.0b 本场赌注（写台词前的必需产物）

有两人以上对话的场景，写第一句台词前先填剧本页模板的"本场赌注"卡（`templates/script-scene.md`）：本场说 ≥3 句的人各一行——

- **持续赌注（出处）**：他这一季 / 这一阶段能得到或失去的具体东西（名单、先发、奖学金、家里、工作、关系），从 `ip.md`、故事正文或分集框架里找，写明出处；找不到就是人物缺口，回 `stage-3b-story.md` §3b.3c "想要"格补，不在本场临时编。
- **此刻向谁要什么 / 怕失去什么 / 为什么是现在**：Mamet 三问（`dialogue-review-sources.md` S6）落到这一场、这个对象。
- **说出口**：他此刻会说出口的那句，逐字写下；或者"不说：理由 __；代价 __"（`character-scene-development.md` §一 隐瞒三问）。
- **场末**：得到 / 没得到 / 推迟，以及代价。被一句"That's fair / Okay"接住就收掉的欲望，代价栏写不出来。

**优先级**：台词先分给卡上的欲望，再核 3c.0a 的约束。承接与埋点能放进动作行就放进动作行；必须由台词交代的，夹进某人要东西的那句里（他为了要到什么才提起它），不单独占一句"回收上一场"。取向 6 与 §五 里的"不替人物总结主题""不解释""克制"管的是赌注**怎么说**，不管**说不说**。

全场都有理由不说时，在卡下登记"本场不说出口：理由"（如余韵戏、赌注已在上一场说尽）；这是记录在案的例外，不是默认。卡是写作依据，不是交付正文；对话内交付时放在剧本页之后，与参数一起按需简短回显。

## 3c.0c 场面轨（写正文前的必需产物：观众看见的画面怎样随时间变）

赌注卡管人物此刻要什么；场面轨管观众在这几十秒里**在哪里、看见谁在做什么、有没有变**。估时 ≥30 s 的场，写正文前先填剧本页模板的"场面轨"（`templates/script-scene.md`）。

**剧本层与生产层的分界**：地点与子空间、人物在做的事（活动）、谁进出画面、时间跳跃、观众这一段新看见什么——属于剧本，是故事的一部分（牛棚里已经蹲好的捕手，是一个处境，不是一个机位）。用什么镜头、机位、景别、运动、切点去看——属于 film-director。场面轨只写前者；写到"侧跟拍 / 近景 / 反打"就越界了。

**先问地点**（John August 场景写作第 4 步："Where could the scene take place?"——最显而易见的地点通常最无趣；`dialogue-review-sources.md` S13）：这场戏放在哪里、人物在那里做什么，才让本场的赌注有看得见的处境？再问第 6 步"这场长还是短"：内容撑得起的时长，与一个画面撑得起的时长，是不是同一个数？

**分段**：地点或子空间变了、主要活动变了、有人进出画面、时间跳了，就另起一段；同一画面里的一来一回不拆。每段写"观众这段新看见什么"——写不出来的段，要么并进上一段，要么说明这段为什么值得观众继续看同一个画面。

**判断**（不是配额）：
- 全场只有一个"地点 × 活动"、没有时间跳、却要演 30 s 以上时，先试让画面推进一次：换一个子空间或活动，时间跳到后果发生的地方，让一个人进来或离开——新画面要带来新处境（谁在等、谁看见、谁离开），不是换背景。试过仍应留在原地的，在表下登记"本场单一画面：理由"：余韵戏、有意一镜到底、困住 / 对峙 / 等待的压迫感就是理由，并写观众在这段时间里看见处境怎么变。
- 同一段画面按估时超过约 40 s，复核：这段是有意的压迫或持续，还是只能靠机位轮换撑着。
- 与取向 8 的关系：取向 8 的"同一地点仍有新作用时不必换景"管跨场重访；场内的对应问题是这一节——**一场之内**，观众也要看见东西在变，变的可以是地点、活动、人，也可以是同一地点里的处境。

**估时**：每段 = 台词秒数（词数 ÷ 语速；THE ORDER 用 4 词/秒）+ 无台词动作。越过、冲刺、过线、看一眼、换到新地点，每一个都要时间，不能被压进台词里；台词之间一两句的反应可与台词同步。总估时写在表下，节拍表不另估。`review_script.py` 按同一方法独立估一遍（`[推论]`，5 场校准误差约 ±15%），自报明显偏小时列复核。

**与赌注卡的关系**：卡先填（谁要什么），轨后填（在哪里、做着什么要）。两张卡不重复：卡的"场末"写人物得到没得到，轨的最后一段写观众最后看见的画面；二者常是同一件事的两面（v4.1：Isa 没答应 → Diego 在牛棚里蹲着等他）。

交给 film-director 时，场面轨是**告知**（本场有哪些场地 / 场景、每段做什么、大致多长），不是锁定：分镜可以重分段、换子空间、换活动或地点，在方案里写明与场面轨的差异；分镜时长超出场面轨总估时 20% 以上只作提醒，回不回剧本层由用户定。场面轨和赌注卡一样是写作依据，不是交付正文：落盘时放在剧本页之前，对话内交付时放在剧本页之后，按需简短回显。短于 30 s 的过场可不填；无台词场同样适用（没有台词时，画面就是全部内容）。

## 3c.1 一场戏的问题

人物侧：谁要什么、为什么是现在（已在 3c.0b 卡上）· 什么挡着或什么在靠近 · 他怎么试 · 结束时什么变了（关系 / 信息 / 物件归属 / 位置 / 决定）。
观众侧：进场时知道什么、期待什么 · 哪个证据改变他们对人物的判断 · 他们看见的画面怎样推进（已在 3c.0c 场面轨上）。
从故事正文与已有场景中理解两侧；已有清单可以沿用，缺表不补表。授权修订可以回写故事。

## 3c.2 节拍表（需要展开交流节拍时，正文后补；估时在 3c.0c 场面轨）

剧情节拍按实际尝试与结果划分，数量由内容和时长决定。可用"尝试 → 受阻 → 调整 → 代价"检查；靠近型场景用"试探 → 允许 / 退回 → 代价"；纯表演测试跳过本阶段。

```
| # | 谁对谁 | 本段交流或行动（策略按需） | 阻力或回应 | 结果或持续状态 | 观众此刻知道 | 落差（若有） | 估时 s |
```

节拍按交流划分，场面轨按画面划分，二者粒度不同；估时统一写在场面轨（台词 + 无台词动作），节拍表的估时列可选，填了须与场面轨一致。估时标明同步与先后；不用平均节拍时长决定镜头。策略列的动词服务演员与分镜，不是台词成立的判据。

## 3c.3 空间即戏剧

按场景需要明确入口/出口、起止位置、相关物件、光与声音。空间是类别名（"医院走廊"）时按 `research-to-craft.md` 补实际陈设与动线。人物关系可以通过距离或表演变化呈现，不强制走位或每场一个道具。画面随时间的推进（地点、子空间、活动、时间跳）在 3c.0c 场面轨，这里只管空间本身与连续性。

影响本场事件或连续性的物件，追踪初态、实际转移与末态：谁拿、在哪、是否开合、由哪个动作改变。写在现有空间/节拍字段，不为所有陈设建表。人物对白可含歧义，动作行里的“她/它/这边”则要能定位；一块布从灯旁到灯下须有转移，不能在 C/D 两层复制同一个遗漏便称保真。

空间承担隐藏、偷听或关系压力时，可按 `screenwriting-methods.md` K1 检查人物可见/可闻/可达的范围。不把剧本开发变成分镜设计：写"观众在哪里看见什么"，不写"用什么镜头看"。

## 3c.4a 从有效入口开发，再检查

可从场景梗概、事件、人物或对白草稿进入。先有一句可信的话也可以；不要先给每句分派策略再让人物填空。依据 `character-scene-development.md` 补确有缺口的交流处境，写出连续片段后审阅。逻辑断裂处再用 `causal-chain.md` 追查，不要求逐句建链。新发现回流故事，不能覆盖用户锁定内容。

## 3c.4 剧本页格式

```
场 XX 〈标题〉 · 地点 · 时刻
动作行：写清人物在场内做什么及可见可听的结果，读者能连续理解。情绪名称不能替代具体证据；保留速度、幅度和渐变信息。
角色名
    台词。
    （括号补实际有用的表演/声音提示，锁定台词不因格式被改字）
动作行：…
```

先写可连续阅读的正文，再补必要生产注释；部位级执行组织仍由 S4 承担，不把 C 层语法提前用作每行动作的写作模板。用户提供或锁定的表演正文完整承接。

动作行应让所选表演可见，例如“她看着他，眼泪积在下眼睑，抬眼忍住”。这只是新编示意；具体通道依场景或原库选定，不因原句抽象便擅加杯子、递物或固定两秒停顿。

## 3c.5 台词

### 场景与交流诊断

统一读 `character-scene-development.md` §四–五。按连续交流片段审阅人物知道什么、为什么此刻这样说、对方如何接收；不要求每句留下上一句的词、不要求每句执行一个及物动词。直接回答、回到早先话题、完整长句和有意重复均可成立。发现问题才定位到具体句子，不把诊断问题变成生成配额。

当任务与感情分成互不影响的两段时用 `screenwriting-methods.md` K2；人物措辞缺来处时用 K3；要保留多解但行动失去依据时用 K4。只写当前所需正文，不堆叠手法。

### 参数关（由场景参数卡决定，见 `scene-parameters.md` §二）
句长、直接表达、停顿、打断与结尾由场景、角色声音和可用时间决定；场景参数不是固定配额。既有台词锁定，仅在用户要求修改时改写。

### 对白审阅（写完整场之后）
剧本页落盘后先跑 `python3 scripts/review_script.py 03_script/scene-XX.md`（多场可一次传入；`--json` 给逐句特征；`--wps` / `--action-sec` 调估时参数）。3.6.0 起总判断另报第三项**画面**：场面轨锚句逐字在正文、顺序一致；估时 ≥30 s 缺轨，或全场一个"地点 × 活动"、无时间跳、未登记"本场单一画面：理由"判为问题；同一段画面估时 ≥40 s、自报估时比文本估时小 15% 以上列需模型复核。对白与赌注两项结论如下：**人物赌注**（逐字核对 3c.0b 的卡——卡上说出口的句子在不在正文、是不是本人说的、有没有人接；不说的有没有理由与代价；缺卡或全场无人说出口且未登记例外判为问题；那句是否真在说卡上那件事交模型复核）与**对白连通**；"对白连通通过"不代表这场人物有戏。连通部分脚本只算可量化项——每句有没有收件人、下一句接不接、两人来回的轮数、句长与无理由短句占比、主谓宾完整度（英文）、画外标注、换到第三人且不接前句的比例——潜台词支点（省略句里当作已知的设定前文有没有建立；用 `--context` 传入 `story-context.md` 指认的前几场）——并把收件人不明、能否同框、"是旧梗还是观众需要的设定"列为"需模型复核"。潜台词无支点时脚本附三种改法（直说来历 / 用当场动作引出 / 让第三人替观众问，各含"改什么 / 这场变成什么 / 影响后面什么"），按 `execution-contract.md` §修改请求 作为改法未定时的选项，不改稿。模型按取向 6（面对谁、刚发生了什么、为什么此刻、说完对方怎么接）复核这些句子，把结论写进同一份 review，按 `SKILL.md` §默认输出契约的诊断格式交付。脚本不改稿，判为通过只表示没触发已知问题；每条判断的一手来源与 `[推论]` 阈值在 `references/dialogue-review-sources.md`。对话内未落盘的剧本页可先存到临时文件再跑。
按共用方法检查交流依据、人物声音与可说性。记录有文本证据的问题、保留项和修订代价；不凭“无问题”三字宣布质量通过，也不因全句工整或双方都激动而自动改写。遇到刻意编排，按 `character-scene-development.md` §五"刻意编排"表找实际原因：场景前提、信息依据、听见了什么、关系与处境、人物是否真会这样说；对白问题不一律用改台词解决。

### 执行信息与空泛描述
- 动作行保留可观察的速度、程度、渐变、持续与控制，不因"逐渐""缓慢"等词而删细节。
- 情绪标签不能代替表演；音量、语速放在"说法"栏。
- 台词自然度由角色与场景审阅，不计副词配额。下表用于决定是否需要补信息，不提供一键替换句式。

| 原句 | 信息作用 | 处理依据 |
|---|---|---|
| "她冷冷地说：随便。" | 态度概括 | 台词保留；需要执行时明确本场已有依据的音量、视线或发声方式，不自动加道具 |
| "他真的真的很想她。" | 内心或对白 | 内心留 A 层；若是台词，重复可能有效，不能机械删字 |
| "他愤怒地摔门。" | 情绪加动作 | 摔门已可见；按场景补力度或结果，不能无依据加灰尘 |
| "她小心翼翼地问……" | 交流态度 | 判断顾虑是什么、对谁说；不强加停顿或“对吧” |
| "他慢慢地走过去。" | 可观察速度 | 保留速度，确需计时时估算距离和时间，不统一改成三秒 |

### 张力六源（可选武器，不是配额）
想说不能说 · 权力转移 · 打断 · 重复变义（回声） · 用动作回答 · 沉默作为台词。参数卡与叙事方式决定哪几源是主武器。

### 每句四件套（需要时）
台词（逐字引号）· 潜台词（A 层）· 说法（音量 / 语速 / 停顿位置 / 说完看哪，写可观察量）· 听者（视线 / 手 / 身体）。30 秒任务或台词很少时可只对关键句写。

## 3c.5b 任务范围提醒

- **优化单集**：先按 `episode-design.md` §一 答承接 / 进入 / 兑现 / 牵引，再写分场；已定结尾与前后集事实不动。
- **只优化对白**：交付只改对白的整段全文；事件、人物设定、场景、结尾不动，不顺手加道具、前史或新事件；说明改了哪几句、为什么（`character-scene-development.md` §五）。范围小不等于改得少：改后每个人都有此刻说这句的理由，两人的声音读得出差别；一方明确表态、另一方让步可以成立，只要各自的理由和口吻是自己的；保留原稿里有效的句子。
- **只诊断**：不交新版本；交付格式统一见 `SKILL.md` §默认输出契约（一句总判断 + 最多三个独立问题，默认约 500 字、最多 800 字）。

## 3c.6 停靠交付（对话内）

每场先交付剧本页全文，生产参数、空间核对与估时说明放在正文后，按需省略。多场交付前做 §3c.6a 连读。下一步只在用户目标范围内推进，实际需要选择才提问。

按 `execution-contract.md` 的保存约定写 `03_script/scene-XX.md`。台词体检（用户已有剧本）：不重写，按共用诊断给出具体证据、可能原因与不确定处；修改需用户要求。

## 3c.6a 整场与整片连读

局部改写也按 `story-context.md` 接读相关前文、新场、受影响后文与远处铺垫，避免提前兑现后场。采用后只记录状态变化和实际依赖；未授权修改的后场列待复核。

从第一句到最后一个事件，按实际呈现顺序只读正文：前场留下的处境能否带入后场，信息是否重复或缺失，人物、物件与声音能否连续，台词、动作与必要停留能否容纳在总时长内；把各场场面轨的最后一段与下一场的第一段连起来看，连续几场是不是同一种画面。同步动作不重复相加，不能因拆成多个 clip 就声称总时长成立。记下具体断点与估时假设后定点处理；这是文本模拟，不是真人排练或生成效果验证。

保存的多场剧本可用 `scripts/assemble_script.py` 按指定顺序汇集正文到 `03_script/reading.md`。这是派生视图，修改仍回各场当前稿；以源文件哈希记录依赖，上游改变后重新汇集，不能反向覆盖场景。没有保存授权时在对话内连读，不创建文件。

## 3c.7 重写

收到批评后按 `creative-loop.md` §二诊断层级并判改法：改法未定且解法不止一种时先给改法选项，不改稿；改法已定后按 §三执行：保留上一版、说明改了什么与解决什么、核对失去的细节、定点改、不换故事。**未被批评的场景设定保留，但改完内容量或估时变了 ≥20% 时，重做场面轨**，在修订账本"场面轨重核"栏写结论：旧地点与活动还装得下新内容吗（EP03 场 4 v4 只换台词，从 61 词到 142 词、估时从 47 s 到 57 s，场景原样保留，画面一直是跑道上跑步）。装不下时，换不换景是改法问题，按 §修改请求给选项，不自动换。改稿是探索稿，采用前不同步故事、框架、正典。示例见该文件 §四。

## 3c.8 常见失败

| 现象 | 处理 |
|---|---|
| 转折只靠一句宣布，缺乏可信依据 | 先查人物为什么改变；直接说出决定可以成立，不自动换成放钥匙 |
| 只有情绪形容，没有可见表现 | 补可观察证据；不按"地"或词性判错 |
| 对视没有戏 | 检查持续压力、变化与目标，有意凝视不强配道具 |
| 台词像同一个人写的 | 查语言经历、交流对象与当前处境；共用日常短句不机械重写，不分配口头禅配额 |
| 场景只为宣布主题而存在 | 重审这场戏发生的理由，不只把宣言口语化（`character-scene-development.md` §五） |
| 台词都在处理剧情账：回收上一场、给后集埋点、交代流程，没有一个人说出自己要什么 | 回 3c.0b：先填卡，台词先分给欲望；承接进动作行或夹进欲望句（THE ORDER EP03 场 4 v3，用户 2026-09-23 否决"平铺说话"） |
| 场景只写了地点：标题、注释、空间都有，整场观众看见的却是同一个画面（同一地点、同一活动，几十秒不变），分镜只能靠机位轮换补 | 回 3c.0c：填场面轨，先试让画面推进一次（子空间 / 活动 / 时间跳 / 进出），新画面要带来新处境；试过仍应留在原地的登记"本场单一画面：理由"（THE ORDER EP03 场 4 v3 / v4 整场跑道，分镜 74 s 靠四种跟拍轮换；用户 2026-09-23 问"整个场 4 都是球场跑步吗？"，定 v4.1 过线后"几分钟后，牛棚边"） |
| 结尾总是一句金句 | 判断人物是否真会这样说；允许直说，也允许不总结 |
| 疑似交错独白 | 查连续片段的回应依据；延迟回应、各执一词也可有意成立，不以句子能换位单独判错 |
| 需求明确要喊出来，却写成沉默对峙 | 具体表达方向被默认覆盖；按需求修正 |
| 每项特征都在，但交流不成立 | 回交流处境查作者安排是否越过人物所知；必要时追查因果 |
| 人物解释制度或工作 | 看听者是否需要知道、人物为何此刻解释；不把合理说明一律当科普删除 |
| 事件超出 30 秒承载 | 保留核心因果与高光，重排同步/先后；不足时在授权内减量或说明时长冲突；拆 clip 不能增加总时长 |
| 重写后原稿的有效细节没了 | `creative-loop.md` §三 第 3 条 |
