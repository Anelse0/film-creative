# 偏好账本

记录用户**明确确认过**的创作偏好，供重写与新项目起步时查阅。它不是规则表：每条偏好都带适用范围与反例，防止一个具体认可被扩大成通用要求。

## 记录规则

- 只在用户确认后记（"这个好"、"就按这种"、"以后都这样"），模型自己觉得好的不记。
- 每条写三件事：喜欢哪种效果（具体到能指出文本证据）/ 在哪类作品、哪种参数下适用 / 反例（在什么情况下不该用）。
- 记"效果"，不记"手法配额"。用户认可"三秒沉默后一句短话"是认可那场戏里的回应关系，不是认可所有高强度场景结尾必须沉默。
- 同一偏好被不同项目反复确认时，只扩大"适用范围"一栏，仍保留反例。
- 用户否定过的做法也记，标"不要"。
- 与用户锁定内容冲突时，锁定内容优先；与表演优先路由的原文保真冲突时，保真优先。

## 使用

- 重写前（`creative-loop.md` §二）先查本表：批评是否已有明确偏好可对照。
- 新项目 S3a 交付时，若本表有与题材或参数相关的条目，在"来路"行提一句。
- 盲测（`tests/creative-eval.md`）结束后，用户确认的判断可以进表，附样本编号。
