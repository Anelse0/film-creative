# 叙事节奏：期待、变化与消化的时间

用于“太慢、太拖、太赶、调一下节奏”。节奏不等于单句台词的字数，也不只是信息越多越好。观众在等什么、怎样重新理解、情绪有没有时间发生，与实际时长共同决定体验。来源启发 S02、S08、S10、S11、S12，见 `craft-evidence.md`；以下诊断和修法为本技能推导。

## 先定位具体断点

读真实前后段，不只看梗概。指出观众在哪一处已经知道结果却仍在等，或还未理解就被推到下一事。必要时用简短记录：观众此刻期待什么 / 接到什么证据 / 人物怎样消化或选择 / 为什么仍要看。静止、重复和无对白都可能很有张力；新信息不断也可能令人麻木。

区分五个尺度：整片的承诺与收束；段落的累积和间歇；场景的进出；交流的往返；身体反应发生所需的时间。只改实际出问题的尺度，不默认重写全片。

## 按原因改

| 具体问题 | 可试的改变 | 必须保住什么 |
|---|---|---|
| 一再复述观众已知的事 | 合并重复交流、晚进入、让后续行动开始承担后果 | 信息首次成立的依据、人物语气与关系细节 |
| 只有结果，不知为何选择 | 补一个能改变人物理解的证据或回应 | 真实动机，不能事后补秘密替转折辩护 |
| 等待无聊 | 明确等待对象，改变可用时间、注意力或失败可能；也可缩短 | 刻意观察和余韵，不能强加威胁 |
| 事件密但没有重量 | 在关键事件后留接收、行动后果或新的相处方式 | 观众仍能追踪主问题，不能批量插停顿 |
| 中段总回原点 | 让前次代价进入下一次尝试，或用重复呈现不同意义 | 人物、资源与关系的连续性 |
| 结局被过早猜完 | 调整观众的问题：由“会不会”转到“如何、代价是什么” | 不为意外抹掉已给证据 |
| 多线切换混乱 | 明确每线眼前目标和时间定位，在相互改变理解处相邻 | 事件时序；交叉剪接不虚构同时发生 |
| 高潮太赶 | 给触发被听懂、抑制失败、选择及余波以必要篇幅 | 不必低声收尾，不配固定三段曲线 |
| 对白本身重复或回应失效 | 直接在授权范围内改句、换接收点或合并话轮 | 锁定文字与必要信息，不机械排成最后一档 |

## 同一材料的两次试读

有不确定性才做：保持关键事实，试改变揭示时机、停留位置或场序，读实际片段。早告知可让观众等待人物发现；晚告知可使先前动作重获意义。两者都可能失效：前者缺少不确定结果，后者没有可回想证据。写清本稿收益与代价再采用，不能只说“更紧凑”。

Nolan 在《敦刻尔克》谈压缩和延长时间；Scorsese 在《爱尔兰人》的讨论把较沉静的节奏连到老年回望。这说明强度不要求永远加速。形式取决于本片要经历什么。

## 台词预算 ≠ 叙事节奏

用户给了时长即可做适配，不需要外部技能回传。实际录音优先；否则给估计区间并注明朗读、动作、反应的假设。并行的动作与台词不重复相加，先听后懂再作决定的过程不能随意压成同时发生。页数、词数只能粗估，不能据此保证成片秒数。

时长冲突时在既有授权内减少冗余、重排或缩小事件范围；逐字台词锁仍有效。必要时呈现具体冲突及可行取舍，不擅自改锁，也不说拆成多个片段就增加了总时长。

修后连读开头到结尾，核等待是否有意义、关键信息能否被接收、情绪是否有因可循。没有真人或成片测试时，如实标为文本走查。
