# 叙事节奏：先诊断叙事，再决定动不动台词

用户说"节奏太慢 / 太拖 / 太赶 / 调一下节奏"时读本文件。**核心结论：节奏的快慢 = 观众获取新信息与经历张力/情绪变化的速率，由叙事结构决定（信息释放顺序、场景转折、赌注升级、节拍密度、场景长度与排序、潜台词与留白），不等于单句台词的字数。** 放慢常常是**加**一个停顿 / 一个眼神 / 一个节拍；加快常常是**重排信息**或**砍掉整个冗余节拍 / 场**——字数不是那个杠杆。

调节奏是**叙事诊断问题**，不是"缩句"操作。台词的增删改是最后一档，且只在诊断指向"某句本身不成立"时做，需授权（硬规则 4）。

## 边界（三种"节奏"分清）

| 层 | 谁负责 | 杠杆 |
|---|---|---|
| **叙事节奏**（本文件） | film-creative | 信息率 / 场景转折 / 赌注 / 节拍密度 / 场序 / 潜台词 |
| 画面·剪辑节奏（镜头长度、切点密度、一句一切、运镜快慢） | film-director `references/dialogue-pacing.md` | 生产侧，不在本 skill 裁决 |
| 台词预算（把台词塞进 clip 秒数的**时长适配**） | 两侧同口径 | 见下 §台词预算 ≠ 叙事节奏 |

用户要"调节奏"默认指**叙事节奏**；只有 film-director 明确回传"超预算"时才是台词预算问题。

## 触发 → 先诊断，别先动手

用户提"节奏"时，先答三问，再选杠杆：

1. **哪一层的节奏**：整片 / 场序（场与场之间）/ 场内（一场里的推进）/ 句内（`dialogue-craft.md` 的 cadence，最后才碰）。
2. **慢 / 赶在哪**：是观众已经知道了还在演（信息重复）、还是没有新问题拉着往前（缺钩）、还是张力平（赌注没升）、还是转折来太晚（场没有价值转变）、还是一次塞太多（信息过载）。
3. **动哪个叙事杠杆**：对症选下表一条；台词增删改放到最后，且要说明动它的理由不是"想变快"，而是"这句本身在解释 / 重复 / 离题"。

先给诊断（哪层、慢/赶在哪、动哪个杠杆），再给整场全文（默认交付）。

## 叙事节奏杠杆表

每条：症状 → 叙事动作 → 与台词的关系。

| 杠杆 | 慢 / 拖 / 赶的症状 | 叙事动作（先做这个） | 与台词的关系 |
|---|---|---|---|
| **信息释放率** `[转述]` Murch | 观众早知道了还在演；或一句里塞太多信息 | 重排揭示顺序：把一条信息推后做悬念、把重复出现的信息只留一处、把过载的一场拆开 | 删的是**重复/已知**的信息，不是"把每句缩短" |
| **场景目标与转折** `[转述]` Mamet 三问 / McKee beat / TV 迷你三幕 | 一场没有价值转变，或转折来太晚 | 给这场一个更早、更清楚的 status-quo shift；没有转折的整场合并或删掉 | 动的是**场**（合并/删/提前转折），不是削句 |
| **赌注升级** `[转述]` McKee / Yorke / `[行业文]` NFS | 张力平，后果不明，观众不担心 | 把代价/后果提前挑明，逐场加码（"拿不到会怎样"越来越重） | 常常是**加**一句点明利害，不是减 |
| **节拍密度与场景长度** `[转述]` McKee（越近高潮场越短、活动越密） | 接近高潮却还在慢慢铺 | 缩短**场**、提高单位时间的动作/反应密度、加快场与场的切换——**场级压缩**，不是句级删字 | 压缩发生在场/节拍层；单句可以照旧甚至更短促，但那是节奏的结果不是手段 |
| **场序与并置** `[转述]` Murch（信息顺序）| 事件顺序让张力泄掉 | 重排场序、并置对照、交叉进行（创作侧提出建议，剪辑落点交 film-director） | 不动台词 |
| **潜台词与留白** `[行业文]` TV craft / `[转述]` Weston·Sciamma | 想要"慢下来"、给人物空间 | **加**一个停顿 / 回避 / 不作答 / 一个眼神节拍——沉默与非言语节拍可与台词等重 | 通常是**加**节拍，不是删台词 |
| **提问—回答链** `[转述]` Yorke / `[报道]` Lindelof（pilot 以问题收尾） | 没有一个"想知道答案"的问题拉着往前 | 给观众一个悬而未决的问题；场尾留钩，答案往后放 | 加的是钩子/问题，不是缩句 |

## 台词什么时候才动（且需授权）

只有诊断指向**这句本身不成立**时才动它，这是"有目的的删改"（`[行业文]` NFS：purposeful cut，不是无差别删台词），是**内容问题不是节奏问题**：

- 在向观众解释、或解释自己上一句（Mamet；`dialogue-craft.md` §一）。
- 与别处重复、删掉不损失识别性/控制过程/关系（`causal-chain.md` 删除测试；August"删掉少什么"）。
- 离题、不推进本场目标。

即便如此：先更新到剧本正文、保留上一版、说明改了什么并核对失去的细节（硬规则 3）；已确认台词逐字锁定，改需授权（硬规则 4）。**为了"更快"而统一砍字/砍句、或删掉潜台词与识别性细节来"提速"，是误用。**

## 台词预算 ≠ 叙事节奏

台词预算是**时长适配**：把台词塞进 clip 秒数（英语 2.5 词/s、对白 ≤ 2/3 clip，见 `dialogue-craft.md` §四、`handoff-contract.md` §四）。它是生产侧的时长约束，**与叙事节奏是两件事**：

- 用户说"调整节奏" → 走本文件做叙事诊断，**不默认走预算精简**。
- 只有 film-director 回传"某 clip 台词超预算"时才做预算精简，且**先重构场**（合并/删冗余节拍/把一句信息挪到可见物件）**再考虑削句**；仍然不指望生产侧拉长镜头承载。

两者会撞在一起：叙事上这场需要一个慢节拍（加停顿），但 clip 秒数吃紧——这时说明取舍（保叙事节拍就要更多秒数 / 保预算就要挪信息），交回用户，不静默砍掉那个节拍。

## 误用信号

- 一提"节奏"就删台词 / 缩句，不做叙事诊断。
- 把"慢"等同于"台词长"、把"快"等同于"台词短"。
- 删掉潜台词、识别性细节或一个必要的沉默节拍来"提速"（违反 `causal-chain.md` 删除测试与硬规则 6）。
- 越过锁定台词改写来调节奏（违反硬规则 4）。
- 把画面/剪辑节奏（镜头长度、切点）当成创作侧的活自己改——那是 film-director `dialogue-pacing.md`。

## 交付

先一句诊断（哪层 · 慢/赶在哪 · 动哪个叙事杠杆），再给**整场全文**（对白场：英文台词 + 中文对照 + 台词设计表；改动到锁定台词需先取得授权）。修订保留上一版可回看，说明改了什么、失去了什么。规则落地不等于质量已证明；节奏是否真的更好以用户判断与盲测为准。

## 来源与核实边界（2026-09-10）

**下列要点本次经 web search 获取，未逐篇通读原文；tag 从严。** 作者实践是启发，转成条件式操作是本 Skill 的设计推论（`[推论]`），不能据此宣称方法适合所有作品或新版编剧能力已提升。

- **Walter Murch，《In the Blink of an Eye》** `[转述]`：节奏/速率取决于此刻观众在看什么；剪辑是决定"何时、以何顺序释放各条信息"；冲突用快节奏、对话用慢节奏；Rule of Six 里 emotion(51%)+story(23%) 远高于 rhythm(10%)——节奏服务情绪与故事。（StudioBinder Rule of Six 综述 / 原著）
- **Robert McKee，《Story》** `[转述]`：越接近高潮"progressively shorten scenes while activity becomes more brisk"——靠**场级**缩短与活动加密加速，不是删单句；beat = 改变情绪值的动作/反应交换，是节奏基本单位；tempo = 场内活动量（对白、动作或二者）；escalation = 逐步加码风险。（Shortform / SuperSummary 对 Story 的整理）
- **John Yorke，《Into the Woods》** `[转述]`：驱动来自欲望 vs 障碍、想要 vs 需要；每场都有推动故事的冲突；结构是分形的（场/集/季各有局部弧）。
- **行业craft** `[行业文]`：No Film School / ScreenCraft / Script Magazine——"pacing is about story and structure, not just speed"；张力来自抬高赌注；"focus on experiences, not dialogue"；收紧剧本时删的是**不服务故事**的场/对白/动作（purposeful cut），不是无差别删台词。
- **电视/showrunner craft** `[行业文]`：Fiveable TV Writing / 《Showrunners》(Tara Bennett) / Scriptnotes 728(Drew Goddard, beats→scenes)——正剧常受益于更慢的节奏以做人物；写进剧本的停顿/看向别处等非言语节拍可与台词等重；单场是迷你三幕（建置→冲突/新信息→改变现状）；showrunner 围绕 act break 建立节奏。
