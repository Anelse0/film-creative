# 导演与影片方法：选机制，不选姓名滤镜

这是问题入口，不是导演百科。证据 S01–S19 及访问范围见 `craft-evidence.md`。表中“写作尝试”均为本技能推导，影片只是方法发生的具体语境。

| 当前问题 | 一手启发 | 本作可试什么 | 不适用或迁移代价 |
|---|---|---|---|
| 人物做事缺生活依据 | Gilroy / Leigh，S03–S04 | 从角色知道的事与实际任务写短场，看看下一句会不会变 | 不凭标签编经历；文本不等于现场即兴 |
| 必要过桥场没有生命 | Sciamma《燃烧女子的肖像》，S02 | 找观众想经历的接近、观看或共同动作；试省略纯连接 | 省掉后看不懂时补最低限度定位，不禁冲突 |
| 故事有事件但无发展 | Mazin，S05 | 改一处选择的后果，追到下一次选择 | 不给每个人强派成长弧 |
| 熟悉故事观众太早看穿 | Gerwig《小妇人》，S08 | 重排同一事实，让现在改变过去的意味 | 需要更清楚的时间辨认，不为非线性而非线性 |
| 情绪只在台词里说 | Dardenne《两天一夜》，S09 | 将支持、依赖或拒绝写进身体和空间关系 | 细节须来自任务；不是摇晃摄影等于真实 |
| 追逐只剩混乱 | Spielberg《决斗》，S13 | 保持目标、威胁与可走路径的相对位置可读 | 不照搬道路、车辆或摄影配置 |
| 危机片越写越快却无压力 | Nolan《敦刻尔克》，S10 | 在关键等待处延长主观感受，压缩重复过程 | 多线信息要可辨；不把历史虚构当事实 |
| 慢段被一律剪掉 | Scorsese《爱尔兰人》，S11 | 看留在过去的叙述者如何改变当下段落的停留 | 沉思不替代具体经验；无效等待仍可删 |
| 有台词节奏却没有交流 | Sorkin《白宫风云》，S06 | 看下一句如何改变前一句的节律和地位 | 不让所有人同样伶俐；生硬可以有意 |
| 名词与行为浮在时代之外 | Eggers《女巫》《灯塔》，S14 | 由气氛和具体材料试出人物与事件 | 细节不是装饰配额，也不要求每个动作都精写 |
| 说明像角色背百科 | Hitchcock《擒凶记》，S15 | 让信息成为当下正在发生的事的一部分 | 观众确需专注信息时，别安排抢注意的动作 |
| 情绪方向与场面动势不配 | Bigelow《拆弹部队》语境，S16 | 决定人物是在赶、等、被困还是失去控制，再组织动作 | 不将所有高强度都写成快速动作 |
| 声音把悬念提前结束 | Fincher《本杰明·巴顿奇事》，S12 | 检查声音是在结束问题还是维持未决期待 | 无需替作曲家写曲；不能直接复制原片处理 |
| 配乐替人物完成全部感情 | Villeneuve / Jóhannsson《降临》，S18 | 分开台词、环境、声音线索和音乐各承担的信息 | 不用“悲伤音乐”挽救空白人物 |
| 每场视听风格都一样 | Lumet《电视台风云》，S19 | 让人物对环境的使用和呈现方式随故事演变 | 不把善恶机械编码成光暗 |
| 局部修句救不了作品 | Lord / Miller《乐高大电影》，S17 | 查人物线与本作欲望是否冲突，重写对应层级 | 先核授权范围，不为追求完美循环推翻 |

用户点名某位导演时，先从其已验证机制中找与本场相关的部分；证据没有覆盖就明确“这里是我的分析”，或继续 search。不能编造“某导演一定会这样拍”，也不复制原片台词或标志性情节来冒充原创。

将选中的机制写进正文：比如让观众先听到某个声音、让一个人保留退出距离、让前场承诺影响下一次回答。没有具体改动，罗列导演名不算应用。若不需解释方法，交付里省略这些名字。
