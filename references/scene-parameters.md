# 场景参数卡

参数描述本次任务，不是固定模板的开关。没有“克制才好”或“强度高就必须外放”的默认美学。

## 一、六个兼容参数

| 参数 | 取值示意 | 判断依据 |
|---|---|---|
| 强度 | 低/中/高 | 场景压力与利害；不从音量或克制反推 |
| 方向 | 内收/外放/变化中 | 是否表达出来；不由强度自动决定 |
| 信息 | 已知/揭秘/不对称 | 谁知道什么 |
| 权力 | 对等/不对等/变化中 | 当前谁能影响谁 |
| 进场温度 | 冷/温/灼 | 开始时已经发生了什么 |
| 密度 | 无台词/稀/中/密 | 台词需求及可用时间，不由方向推断 |

只回显有用参数。缺项可暂留未指定；只有歧义会实质改变任务才问。旧项目六参数行仍可用。角色/节拍情绪强度、克制、高光和末态独立记录（具体写作见 `emotion-dramaturgy.md`），不把场景“高”传播为所有角色动作大。可用 1–5 内部尺度或自然语言，不是 API 参数。

## 一b、表的读法

用户锁定内容、真实技术限制、正文保真是约束；峰值形态、句长、结尾和通道数量是创作判断。以下是选择依据，不是必须出现的特征。

## 二、参数怎样参与决策

### 台词（S3c）

内收也可以直接说清，外放也可以回避；方向不指定句法或交流策略。按 `character-scene-development.md` 判断本场说法，不强制升级阶梯、低打击、断句或结尾不和解。句长由人物声音、内容与可用时间决定，已确认台词逐字保留。动作行保留速度与渐变，不按词性删字。

### 表演外化 / 分镜 / 模型执行（生产层）

参数只在交接有用时附，不默认建卡。剧本行为由本技能写作；技术分镜与模型执行需要用户另行选择制作流程。

### 结构（S3b）

从进场状态与目标末态反推事件。允许持续升温、降温、平台或转折，不固定 30 秒曲线，也不按比例缩放到 10 秒。表演先分配高光时间，剧情按事件承载时间，均检查负载。

## 三、组合而不是预设

同样高强度可以大声争执，也可以无台词强克制；同样是笑，可以眼角参与，也可以嘴笑眼不笑。根据表现选择，不把题材名映射成固定组合。

## 四、误用信号

- 持续大哭因“峰值”被改成停住。
- “强度高”自动带来台词多、动作大、镜头多。
- 克制只靠减少文字，没有控制行为。
- 每种情绪用相同秒段、通道与结尾。
- 参数卡覆盖用户确认的原文、台词或分镜。
