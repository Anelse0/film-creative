# 成果与文件格式

本文件统一交付格式；保存授权仍只由 `execution-contract.md` 判断。正文先行，工作记录按需，模板是起点而非必填清单。用户已有格式优先；只保存既有稿时逐字保存，不主动套新模板。

## 交付什么

| 用户要的成果 | 默认阅读形式 | 不当成正文的内容 |
|---|---|---|
| 概念 | 标题、具体人物处境及发展可能；多候选写实质差别 | 内部检索过程、默认地图、诊断清单 |
| 故事 | 有人物、事件与因果/体验连续性的叙述正文；故事需完整时写到结尾 | 只给节拍表、人物小传或方法解释 |
| 剧本 | 场头、动作、人物名、对白，按实际呈现顺序连续阅读 | 策略表、逐句潜台词分析、修订账本 |
| 评审 | 问题所在原文、影响、建议，保留有效部分 | 未经授权直接覆盖原文 |
| 对白场交接生产 | 剧本正文，按实际需要附硬锁、行为先后和 `../templates/dialogue-design-sheet.md` 中的相关注记 | 不默认双语、逐句表或承接说明 |

短任务直接交正文。多个候选尚未决定就标候选；自主选择沿用授权，不伪造“用户确认”。长篇分批交付时列明实际完成场次与剩余范围，保存项目更新进度；后续批次重新接读已完成场次和全局依据，不把大纲、节选或“其余略”称作完整剧本。

## Markdown 当前稿

新保存项目沿用 `01_concept.md`、`02_story.md`、`03_script/scene-XX.md`。需要版本追踪时标题后仅列真实版本、状态（草稿/已采用/用户确认）及日期；无保存授权不创建目录，不为填模板编作者、版权、审批人或研究结果。旧稿保留方式见 `project-state.md`。

剧本用 `### 场 01 · 内景 · 地点 · 夜` 场头；动作单独成段；人物名独立加粗，下一段是对白。对白不缩进四格（Markdown 会变成代码），不写“动作行：”标签。括号提示只有在说话对象、声音来源或理解确需时才加，不逐句规定情绪、视线与秒数。画外现场发声与旁白/内心声音区分标记；同时对白说明同时，不能排成先后却称同步。

场头与所有正文放在唯一一对 `<!-- script-body:start -->` / `<!-- script-body:end -->` 中。元信息和必要的上下文/修订说明置于标记之外。未填写说明与占位符交付前删去；正文不可有省略占位。用户锁定的标点、重复、空行等不得因格式整理被改写；既有排版需要改变时保护原文件，只创建获授权的阅读副本。

## 多场阅读版

只在需要并已获保存授权时，按**故事采用的呈现顺序**传源文件，不能按文件名排序猜测（插叙也不按事件发生时间排序）：

```sh
python3 scripts/assemble_script.py 03_script/scene-02.md 03_script/scene-01.md --output 03_script/reading.md
python3 scripts/assemble_script.py --verify 03_script/reading.md
```

工具保留正文内容与输入顺序，剔除标记之外的注释，生成 `reading.md` 和 `reading.sources.json`。新清单以相对清单目录的路径和 SHA-256 记录来源与顺序。校验检查来源、输出哈希及重新拼接结果；失败时先查变动，回源稿修订再重建。旧绝对路径清单仍可校验，跨目录移动后可能需重建。源文件不得被覆盖；已有非工具生成文件或被改过的阅读版拒绝覆盖，应另选路径或先明确处理其改动。

写入前解析全部来源并暂存两个新文件，常规提交失败回滚；系统崩溃/并发写入不保证两文件事务性。工具成功或哈希通过只说明文件一致，不证明故事、对白或时长成立；完整连读仍按 `stage-3c-script.md`。

## 交换格式（仅按需求使用）

需交给支持 Fountain 的编剧软件时可用 `templates/script.fountain`，依据 [Fountain 官方语法](https://fountain.io/syntax/)（2026-09-11 search 核对 Scene Headings / Character 段）：`INT.`/`EXT.` 场头、`@中文人物名`、人物名后紧接对白、动作另段。模板为语法示意，必须替换占位；它不经过 Markdown 汇编器，也没有自动 Markdown → Fountain 转换。转换旧稿时逐项核台词和场序，不把改扩展名当转换。遇到 `*`、`_`、`[[ ]]` 等具有格式意义的原文，按目标语法处理并在目标软件核读。

PDF、DOCX、FDX 仅在用户要求且实际生成、打开验证后交付；不把 Markdown 重命名冒充这些格式。页边距、字体、分页按交付方要求；中文朗读和动作时长单独估计，不套“一页一分钟”。
