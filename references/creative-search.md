# 从已有材料长出创意

S3a 构思、S3b 发展和 S3c 加戏/改戏时用。目标是产出可读、可比较的故事与场景，不把任务变成方法报告。没有具体困难时直接写；用户只要一个成稿，不把内部尝试全部展示。

## 先找值得发展的矛盾或吸引力

抓住材料中一个具体的未完成之处：两个人对同一件事的理解不同、已经许下却难兑现的承诺、一次帮助带来的负担、角色珍惜的两样东西无法同时保住，或值得停下来观察的共同生活。不是给每个人补旧伤，也不是要求所有故事有矛盾。

把抽象愿望落到体验：“关于孤独”还不能开戏；“一个人想让对方多待一会儿，却不断替对方把走前的事做完”已有行为张力。这是方法示意，不能复用为候选答案。

接已有故事时先按 `story-context.md` 建立本场依据。**锁定的是边界，开放的是回应、后果与呈现方式**；未知的既有事实不是可随意填的空白。

## 选择能改变作品的一种探索

按实际问题选用，不轮流填表，不规定候选数或反转数：

| 困难 | 实际尝试 | 必须检查的代价 |
|---|---|---|
| 候选只是换地点/职业 | 保持题材，改变人物如何理解处境、彼此要什么或愿承担什么，写出不同后果 | 是否越过已定关系；不是只换包装 |
| 事件可猜、人物像棋子 | 在同一边界内，让角色选择另一种有依据的回应，追到下一次选择 | 新回应是否属于这个人在此刻；不能靠降智拖延 |
| 只能想到加坏事来升级 | 从上一次成功/失败产生代价，或让两项原有愿望互相牵制 | 代价从前文长出；不要临时加反派、疾病或规则漏洞 |
| 场景只是完成交代 | 找人物在完成同一件事时各自关注什么，让任务与关系互相影响 | 必要信息仍可理解；场景不能仅靠作者解释才有趣 |
| 只有对抗，关系很单薄 | 试合作、试探允许、共同维护某事、看见对方此前忽略的一面 | 不突然和解、不洗掉旧后果；没有争吵也需要具体体验 |
| 结尾有力，中段只是过桥 | 从结尾倒查所需的认识/选择，再向前试不同到达方式 | 不倒造前史替结尾辩护；有权改暂定结尾时也可改结尾 |
| 信息全靠最后宣布 | 保持事实，试不同的知情者或揭示时机，写实际段落 | 区分角色与观众；不能把未来事实给过去的角色 |
| 台词只在表达情绪 | 保持事实和交流目的，试此人怎样让这个听者理解/误解/接受 | 从人物声音与听说关系发展，保留已有效的具体原句 |

现实细节能打开选择时按 `research-to-craft.md` 查有针对性的材料。一个有关操作、称呼或空间的发现，要先改变人物的实际选择再进入正文；不要把研究堆成背景，也不搜索现成故事搬用。

需要把探索变成具体编剧操作时，按 `screenwriting-methods.md` 选对应一项：人物不可信用 H2，中段重复用 H3，空间/社会条件悬空用 K1，任务与感情割裂用 K2，措辞不属于人物用 K3，悬念缺依据用 K4。H1 用于全片作用与局部体验失配。

## 写出差异，再选择

需要探索时先写最能暴露不确定性的正文片段或事件段，不能只交“可以更有张力”。关键不是候选数量，而是不同选择会使谁失去/得到什么、观众为何愿意看下去。

比较时先遮住标题、意图和优点说明，只看正文：

1. **是否属于这部作品**：与设定、进场状态、后续承诺和本轮范围相容。违反硬锁的方案不能凭精彩抵消问题。
2. **是否有具体创作收益**：哪句回应、哪个决定、哪段观察带来了新的理解、情感、喜剧或持续注意？不要用“高级/电影感”代替证据。
3. **收益要付什么代价**：多了多少解释、新前提、时长或后场修改，失去了原稿哪一处有效细节？代价大不自动淘汰，但必须在授权与作品需要内。

熟悉但具体的写法可以胜过陌生而空泛的设定；遵守边界也不等于创意已好。都平庸时，回到人物真正关心的事或补一个材料缺口，不不断更换修辞。一个试稿已解决问题就停，无须凑比较轮数。

## 让发现留下来

采用时直接保留有效正文，把发现写回本故事的假设、人物处境或后续选择；按 `creative-loop.md` 核改稿得失与范围。不要把有生命力的片段压成概念，再凭记忆重写丢失细节。被否定的分支只记否定原因，下一轮改变对应的创作变量，不再换个标题重交。

这些操作综合编剧实践与生成研究，是本 Skill 的工作设计，未经过独立创意盲测；来源和迁移边界见 `context-creativity-sources.md`。


## 人物成功以后，故事还会长出什么（K5/K6）

当创意只剩“再来一个更大的障碍”时，试让人物在既有规则内成功，再写他如何面对成功的后果：得到了什么、现在怎样使用、对谁有了新的责任。不要先加灾难；从人物最珍视且已经有依据的东西，写一段实际选择。目标改变须来自他经历过的事，不能靠突然揭露新前史来救场。

群像可让同一事件进入不同人的生活：同一笔收入，有人先还债，有人想保留共同事业，有人希望获得退出自由。下一场应由这些选择的相遇产生，不能让三个人依次讲同一个道理。结尾可以回到开头同一个问题，写现在不同的回答与行动；不强制反转、惩罚或所有人达成共识。

若试写改变了目标或叙述视点，按 `story-context.md` 回核前场铺垫、叙述者能知道什么和后场承诺。开放开发可修上游；局部改稿若超范围则保留为备选建议，不能默默改正典。来源及推论边界见 `craft-sources-1.2.0.md`。
