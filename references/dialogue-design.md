# 台词设计：从听者的反应写出下一句

用于新写、扩写对白，以及“台词都像作者”“每句漂亮但交流不成立”的修订。已有稿先按 `story-context.md` 取故事依据；声音基础和诊断分层沿用 `character-scene-development.md`。以下是 Skill 的方法提炼，不是专家原话或逐句打分公式。依据见 `craft-evidence.md` S04、S06、S07；情绪与交流联动见 `emotion-dramaturgy.md`。

## 先找到这一段为什么发生

从实际处境中抓住：谁对谁说、双方分别知道什么、此刻在处理什么、说完对方可能做什么。可以是请求，也可以是共同回忆、交代工作、讲故事或陪伴；不强行解释成争夺权力。已有可信台词可直接作为入口，缺口只补本段所需。

人物声音由语言经历、当前对象和当下状态共同决定。选择确有依据的差别：怎样称呼别人、注意哪些细节、举什么例子、如何开玩笑、解释到什么程度。身份标签和口头禅不能替代声音；同一个人面对母亲、客户和朋友可以不同。资料里的外语表达先理解交流作用，再写适合本作的中文，不直接移植敬语等级或翻译腔。

## 写一段完整交流，再定点改

1. 写实际对白与必要动作，不先给每句贴策略标签。让人物讲眼前真正需要讲的事；直说、长句、沉默和修辞都可以。
2. 转到听者的位置：他听懂、误解、在意或忽略了哪部分？下一句或行动如何受它影响？误解须有措辞、知识或处境依据，不能为了拖戏让人突然听不懂。
3. 连读整个片段，找交流失效的具体位置。回应可以延迟，沉默也可以没有隐情；不要求每句复用上句词语。群戏先分清谁听见、谁接话、旁观者何时进入，不能让所有人轮流发表主题感言。
4. 只对问题段试一个有实质区别的改法。例如：改变人物愿意承认的程度、听者抓住的信息、解释顺序或玩笑对象；不是把同一句换三套同义词。比较实际正文与前后场代价，保留更适合本作的版本。
5. 在脑中按角色轮流读完，核称呼、指代、呼吸和信息承接；这是文本模拟，不声称做过真人围读。锁定台词逐字核对，知识新增核回故事，必要修订才记录到采用稿。

## 常见需求的具体入口

| 需求 | 可执行尝试 | 失效时查什么 |
|---|---|---|
| 自然但不能平 | 写出听者对某个细节的具体反应，让说者据此继续 | 不靠批量添加“嗯、那个”制造自然 |
| 有潜台词 | 分开人物说出的事与希望对方领会的事，给听者可接收的依据 | 用户要求明确表白或告知时不强行藏起来 |
| 长篇解释/独白 | 明确为什么此人此刻愿意听、哪里改变听者理解；保留必要完整推演 | 不按句长删信息，也不为体现互动硬插话 |
| 喜剧或机锋 | 从人物认真维护的面子、错误预期或不同关注点试一个回应 | 笑点不能靠泄露人物未知事实或贬低智力成立 |
| 风格化/文雅台词 | 在同一文风里区分各人的关注、比喻来源和表达习惯 | “不像日常聊天”不是自动退稿理由 |
| 同一句反复出现 | 比较每次对象、处境、听者反应；意义有变化就保留 | 没有变化且无节奏作用时才压缩 |

## 小例：说明成为关系事件（原创示意，不作答案库）

已知：店员小林刚收到外地录取通知，还没告诉母亲；师傅只知道她询问转让店铺的手续。

**师傅**

转让要房东签字。你妈签了没有？

**小林**

她还不知道我要走。

师傅把合同翻回第一页。

**师傅**

那先别填日期。

最后一句回应的是小林新说出的家庭处境，仍在处理合同。它不需要让师傅突然知道录取学校。若母女前场已谈妥离开，这段便不适用；不能倒改前场来保住“好台词”。
