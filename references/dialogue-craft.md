# 台词工艺：逐句可检的规则

`dialogue-design.md` 讲怎样从听者反应写出下一句；本文件是**逐句检查表**，用于新写完成后与用户说"台词不行 / 没逻辑 / 太牵强 / 这句是什么意思"时定位问题。规则来自一手创作者资料的提炼，标注出处与证据强度（`[一手]` 已读原文或原讲稿 · `[第三方转述]` 经转载或课程整理 · `[推论]` 本 skill 的设计推论）。它们是检查项，不是配额：直说、长句、修辞与沉默都可以成立，前提是人物此刻会这样说、听者能接住。

## 1. 每句在做一件事（台词即行动）

- **一句一个动作**：每句台词是说者对听者做的一件事（试探、挡、戳、示好、宣布、收买），能用及物动词写出来；写不出动词的句子多半是在向观众解释。— David Mamet 致《The Unit》编剧组备忘录（2005）：每场戏要回答"谁要什么 / 拿不到会怎样 / 为什么是现在"，"观众不会为了信息而看" `[第三方转述]`；Aaron Sorkin 讲"意图与障碍"（intention and obstacle）是戏的最小单位 `[第三方转述]`。
- **删除测试**：删掉这句，场面少了什么？说不出 → 删。承载识别性、回应关系或控制过程的句子不算"可删"（沿用 `preference-ledger.md` 2026-09-04 条）。— John August, *How to write a scene*（2007，johnaugust.com）"这场戏必须发生什么 / 删掉会怎样" `[一手]`。
- **场要转**：一场对白结束时至少一项改变（信息 / 关系 / 位置 / 决定），或明确写"持续状态，有意不转"。— Robert McKee, *Dialogue: The Art of Verbal Action*（2016）：对白是"言语行动"，场景以价值转变为单位 `[第三方转述]`。

## 2. 潜台词与直白

- **说的与要的分开**：写出人物说出的事与希望对方领会的事；两者相同不算错，但连续多句相同就是"照本宣科"（on-the-nose）。用户明确要表白 / 告知时不强行藏。— McKee 同书；Scriptnotes 609 *Dialogue and Character Voice*（2023，johnaugust.com 文字稿）关于"人物只替下一情节点服务"的讨论 `[一手]`。
- **不解释自己刚说的话**：一句"我之所以说……"通常是作者在补漏。要么让上一句本身站住，要么让听者的反应替观众提问。— 用户 2026-09-08 否决"And the reason I said 'for now'?" `[项目确认]`。
- **听过的台词就是陈词**：任何你听过别人说过的台词都已是 cliché——听起来熟的句子先换成此人此刻才会说的话。— Shonda Rhimes, MasterClass《Writing Authentic Dialogue》（R1 `[一手页面]`）。
- **听者不需要的信息不说给听者**：向熟人解释双方都懂的背景只为告知观众 → 移到需要它的人面前或画面里（`character-scene-development.md` §五）。

## 3. 比喻、金句与"漂亮但要解释"

- **一秒落地测试**：听者（含非母语观众）在一秒内能否听懂并知道说者要什么？"钥匙 / 名字能敲开门 / 钱比建筑还老"这类需要二次解码的比喻在短剧里落不了地。— 用户 2026-09-07 三次否决 `[项目确认]`；Scriptnotes 609 关于"可记忆性 vs 交流成立" `[一手]`。
- **收尾不必金句**：最后一句可以是回应或动作；只有人物真会这样总结时才总结（`creative-loop.md` §四"我今天回来了"）。
- **修辞要有来处**：文雅、排比、双关须属于这个人的语言经历与此刻对象（`screenwriting-methods.md` K3）。

## 4. 声音区分

- **遮名测试**：遮住人名读一段，能否分出谁在说？分不出时从"称呼谁 / 注意什么细节 / 举什么例子 / 解释到什么程度 / 敢不敢直说"找差别，不派发口头禅或方言配额。— Scriptnotes 609 `[一手]`；`character-scene-development.md` §四。
- **地位在句法里**：高地位的人短句、少解释、不重复对方的词；求人者句子变长、开始解释。反转它时要有可见依据。— Keith Johnstone, *Impro*（1979）status 章 `[第三方转述]`。
- **同一人按场合变声**：面对权威 / 同伴 / 恋人 / 全场麦克风时称呼、解释量与句长不同（`dialogue-design.md`）。

## 5. 用冲突交代世界（先导片的规则与组织）

- **信息优先用可见物件带出、pilot 以问题收尾**：关键信息尽量由可见物件带出而非独白；先导片结尾留一个问题而不是答案。— Damon Lindelof（L1 `[一手访谈报道]`）。
- **规则由有权者宣布、由受影响者接住**：世界规则（组织、赛制、淘汰）在台上宣布时，切给台下会因此受损或得利的人的反应，规则就有了戏；单纯念规则是信息倾倒。— Craig Mazin, Scriptnotes 403 *How to Write a Movie*（2019，文字稿）：中心戏剧论题通过人物选择而非说明推进 `[一手]`；`series-engine.md`。
- **不揭结果**：宣布候选 / 规则可以，宣布赢家留给后续；先导片留下"谁会被刷掉"的问题，不回答。— Pamela Douglas, *Writing the TV Drama Series* 论 pilot 留下引擎与问题 `[第三方转述]`。
- **命名统一**：组织名、赛事名、头衔按 `ip.md` 逐字使用；大小写 / 冠词的区分（组织 vs 场地）要在第一次出现时被听者接住一次。

## 6. 语域：美式青春 / 精英剧的当代英语

- **短、具体、可说**：对话句多为 3–12 词；名词具体（the Cup、the roster、your arm）而非抽象（destiny、legacy）；俚语点到即止，不写会过期的网络词。`[推论]`，可对照 Scriptnotes 609 关于"人物只说自己会说的话" `[一手]`。
- **正式场合仍是人话**：会长致辞、教练训话用完整句与并列排比，但每句一个信息；"you'll earn it — in front of us" 式的短促收束比长从句更像台上的人。`[推论]`
- **旁白是报道不是抒情**：第三人称报道式旁白只陈述可见事实与规则，不评价、不点主角名（用户 2026-09-07 定稿）`[项目确认]`。

## 7. 竖屏短剧的密度与节律

- **每集一个 cliffhanger、每 20–30 秒一次落点**：竖屏平台单集 1–2 分钟、每集结尾必有钩子（ReelShort 报道，V1 `[一手报道]`）；落点＝新信息 / 关系变化 / 收束句；一场戏进入时观众已知的东西不再重复（20–30 秒节律为 `[推论]`）。
- **台词预算**：英语约 2.5 词/s，对白 ≤ 2/3 clip；30s ≈ 50 词 ≈ 5–7 句。超预算精简台词而非拉长镜头（`handoff-contract.md` §四）。
- **hook 与 button**：场首一句要让人想听第二句，场尾一句让场面合上或翻面（`beat-to-dialogue.md` §4）。

## 8. 双语坑：中文设计 → 英文台词

- **先写英文再对照**：先按角色声音写英文，再给中文对照；先写中文再直译会带出中式语序与成语比喻（"钱比这还老"即直译事故）。出海短剧行业的做法同样是由懂双方套路的编剧重写、而非逐词翻译（V2 `[第三方行业文]`）。`[推论]`
- **中文意图 ≠ 英文措辞**：用户给的中文意思（"打抱不平""不舒服""嚣张不了多久"）是意图锁，不是要逐字翻译的句子；用英语母语者在此处境会说的话承载同一意图。
- **成语与俗语不过桥**：中文成语、四字格、谚语不直译；找英文里同功能的口语表达或改为具体陈述。
- **称呼与人名**：英文口语中直呼名字的频率低于中文习惯；一段对话里名字出现一次通常够。`[推论]`
- **中文对照的作用**：对照是给中文读者核意图的，不是第二版台词；两者意图不一致时改英文或改对照，不留歧义。

## 9. 逐句检查（交付前过一遍）

1. 这句对听者做了什么（动词）？
2. 删掉少什么？
3. 说者此刻知道这件事吗？听者能接住吗？
4. 有没有在向观众解释？有没有在解释自己上一句？
5. 比喻 / 双关一秒能落地吗？
6. 遮名能认出谁说的吗？
7. 这场结束时什么变了？收尾句在哪？
8. 碰到引擎了吗，还是只在私人线（有意）？
9. 组织 / 赛事 / 头衔名与 `ip.md` 逐字一致吗？
10. 台词预算在 clip 内吗？
11. 英文是先写的还是译出来的？
12. 用户逐字给的句子原样在吗？

出处与证据强度汇总见 `craft-sources-1.3.0.md`。规则落地不等于质量已证明；创作增益仍以用户判断与盲测为准。
