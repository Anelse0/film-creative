# 台词工艺：好莱坞 · 欧洲 · 韩国的方法，提炼成逐句可检的规则

`dialogue-design.md` 讲怎样从听者反应写出下一句、`beat-to-dialogue.md` 讲节拍草稿怎样变成台词；本文件是**方法论层**：把三个体系里关于对白的一手方法提炼成可以逐句检查的规则，并在末尾给出检查清单。每条标出处与证据强度（`[一手]` 已读原文 / 原讲稿 / 作者本人页面 · `[原著要点]` 依据原著与其可回访的页码摘录，未在线通读全书 · `[报道]` 一手访谈的媒体报道 · `[转述]` 课程页 / 二手整理 · `[行业文]` 行业教程或标准的转述 · `[推论]` 本 skill 设计推论 · `[项目确认]` 用户在实际项目里确认或否决的效果）。出处与链接见 `craft-sources-1.3.1.md`。这些是检查项，不是配额：直说、长句、修辞与沉默都可以成立，前提是人物此刻会这样说、听者能接住。

## 一、好莱坞：对白是行动，不是信息

**Mamet（《The Unit》编剧备忘录，M1 `[一手]`）**
- 每场三问：**谁要什么 / 拿不到会怎样 / 为什么是现在**。答不出的场不是戏。
- "观众不会为了信息收看，只会为了戏留下"——一句只为让观众知道背景而存在的台词，要么给它一个此刻需要这条信息的在场听者，要么删。
- **沉默电影测试**：把对白全部拿掉，观众还能从人物做什么、拿什么、看什么读出这场戏吗？读不出，说明戏在台词里而不在行动里。
- 删掉"两个人谈论第三个人"和"披着对白外衣的说明"的场。

**Sorkin（MasterClass，S1 `[转述]`；No Film School 综述 `[转述]`）**
- 戏的传动轴只能是**意图与障碍**；没有，就是新闻报道。检验法：对意图"按一按"（press on it）——不紧迫的意图撑不起场。
- 对白是音乐：节奏（cadence）、调（tone）、音量（volume）三件分别调；**读出声**，卡住即节奏断；一句不落地时试着**加或减一个音节**。

**McKee（《Dialogue: The Art of Verbal Action》，K1 `[原著要点]` p.46–52）**
- 三层：**说出的（the said）/ 未说的（the unsaid，只对自己说）/ 说不出的（the unsayable，人物自己也不知道）**。写每句先问：这句在哪一层？听者能从"说出的"里读到多少"未说的"？
- 对白的双重功能：能说的部分塑造**表面人格**（characterization），说不出的部分透露**真实人格**（true character）——后者只能靠行动与选择呈现。
- 对白是**言语行动**：每句改变对方或局面一点；一场戏以价值转变为单位（`character-scene-development.md` §一）。

**Truby（《The Anatomy of Story》，T1 `[原著要点]` p.373–380, 138–139）**
- 好对白是**交响不是独奏**，三轨同时进行：**故事对白**（发生了什么）/ **道德对白**（两种做法、两种活法的争论）/ **关键词**（反复出现、在不同语境累积意义的词或短句）。只有一轨＝平庸。
- 道德对白最常见的位置：**盟友批评主角为了目标使用的手段**——这比反派的威胁更能写出主角的两难。
- 关键词的做法：让人物说这个词的次数**多于正常**，且在多种语境里说，意义靠累积。（署名 / 名字 / "earn it" 这类母题词按此运作。）

**Weston（《Directing Actors》，W1 作者页 `[一手]` + 摘要 `[转述]`）**
- **情绪不可演，动词可演**："难过"没法演，"求她 / 挡他 / 逗她"可以。台词设计表的"目的动词"列由此而来；"说法"列写可观察量（音量 / 语速 / 停顿 / 重音），不写形容词。
- **潜台词要比文本响**——一句话能被演出来的前提是它底下有另一层意思。
- 调整（adjustment）可以是私密的：一方带着对方不知道的前提说话，交流就有了不对称。

**Snyder（"Pope in the Pool"，B1 `[转述]`）**：必须交代的信息，放在观众正被别的东西吸引的时候说（有趣的动作 / 反常的场合 / 一个笑点）——说明和吸引力同时发生。

**Rhimes（MasterClass《Writing Authentic Dialogue》，R1 `[转述]`）**：任何你听过别人说过的台词都已是 cliché；pilot 第一幕交代人物与世界，开场要让人 lean in（不等于必须动作）。

**Lindelof（Television Academy 访谈，L1 `[报道]`）**：关键信息尽量用可见物件带出而非独白；pilot 以一个问题收尾而不是答案。

**Scriptnotes（A1–A4 `[一手]`）**：August《How to write a scene》——这场戏必须发生什么 / 删掉会怎样 / 三种进入方式；609——人物是否只替下一情节点服务、可记忆性 vs 交流成立、声音差别的来处；403（Mazin）——中心戏剧论题靠人物选择而非说明推进；693——铺垫要先作为当下的行动成立，兑现时观众才回想起来。

**修 on-the-nose 的操作（O1 `[行业文]`）**：先写**直白版**（人物说出全部所想），再对每句写 2–3 个"绕着说"的版本，选潜台词最厚而听者仍能接住的；用户明确要直说时保留直白版。

## 二、欧洲：张力不只来自冲突，地位写在句法里

- **Sciamma（BAFTA 讲座，`[一手]`，见 `screenwriting-traditions.md` §五）**：区分"想要的场"与"剧情需要的场"；**没有冲突不等于没有张力**——欲望、允许、距离的变化也是张力源；台词可以是靠近而非对抗。
- **Yorke（《Into the Woods》，Y1 作者站 `[一手]`）**：**想要是意识的，需要是无意识的**；中点是人物第一次拥抱自己所需品质的时刻；结构是分形的——一场戏、一集、一季各有自己的局部弧。写台词时分清人物此刻说的是"想要"还是"需要"，两者矛盾处最有戏。
- **Johnstone（《Impro》status，J1 `[转述]`）**：地位由言语与身体的微小选择体现：高位者句短、声冷、不重复对方的词、不解释；低位者句首犹疑（'er' 在句首邀请打断）、解释多、句子变长。地位是**跷跷板**——一方上，另一方下；一句台词让谁上谁下，写之前想清。
- **Kaufman / Eggers / Gilroy（BAFTA 讲座，`[一手]`，已在 1.1.0）**：不过早定死；人物语言、工作与空间要有研究依据；先试写对话再找故事。
- 欧洲片常见的克制对白（Haneke、Dardenne 等）本版**未取到一手方法文本**，不列规则；不据"欧洲感"删台词。

## 三、韩国：挑词、克制、人人是自己故事的主角

- **金银淑（KOFIC 访谈，KE1 `[一手]`）**："从读诗和读文学里被一句话抓住的记忆，一直影响我写台词的方式"；把**不常见的词放进日常剧**；"要把可怕的处境写得迷人"；不赶稿。→ 操作：每场至少一句让人物用**只有他会用的词**说一件普通的事；高强度场面找一个反差的、带魅力的说法，而不是提高音量。
- **卢熹京（Korea Times 报道，NH1 `[报道]`）**：为《Our Blues》看了 100 多部纪录片、在济州住了两年；不再写"两个主角＋配角"，因为"每个人都是自己故事的主角"；难的时刻用**克制与简洁**写出力量。→ 操作：群戏里每个说话的人都有自己此刻要保住的东西（`screenwriting-methods.md` H2）；痛处用最少的词。
- **朴海英（Asia Business Daily / STARNEWS，PH1 `[报道·弱]`）**：拒绝解释自己的作品，让观众自己接收；台词以"余韵"著称；导演要求演员**一字不差**地演她的台词与动作指示。→ 操作：结尾句宁短勿总结；台词与动作指示是一体设计的。
- **郑瑞景（1.2.0 D2/K5/K6 `[一手]`）**：人物措辞有来处，听者理解有过程；调查的过程就是了解对方的过程。
- **奉俊昊 / 朴赞郁 / 李沧东（1.1.0 K1/K2/K4 `[一手]`）**：空间与日常条件参与因果；同一件事承载任务与关系；保留不确定性同时给行动依据。
- **韩剧结构（综述，KS1 `[转述·弱]`）**：单一编剧写完整故事、16 集容器、每集结尾留钩但大结局给答案、边拍边写按反馈调整、四幕对应广告段。→ 只取"每集结尾留钩、结局给答案"和"单一作者的整体感"两点。

## 四、竖屏短剧（中 / 美）：钩子、卡点、每集留悬念

- **ReelShort（Deadline 2026 / TIME 2024，V1 `[报道]`）**：单集 1–2 分钟、一季 70–80 集、每集结尾 cliffhanger、前 8–13 集免费后付费卡点。本地化靠**懂双方套路的编剧重写**，不靠直译（Artlangs，V2 `[行业文]`）。
- **国内短剧编剧教程与行业标准（红果编剧第一课 / 爆款拆解 / T·CEAP 1—2025，Z1–Z3 `[行业文]`）**：前 3 秒钩子三类（直接冲突 / 强悬念 / 极致反差）；单集 1–2 分钟约 550–800 字，"冲突→升级→反转→留钩"；每 5–10 集小反转、20–30 集大反转；六幕"起-困-反-升-爽-合"，每集必留悬念与情感驱动。→ 对 3–5 分钟的先导：每 20–30 秒一个落点（新信息 / 关系变化 / 收束句）`[推论]`；场首一句让人想听第二句，场尾一句合上或翻面。
- **台词预算**：英语约 2.5 词/s，对白 ≤ 2/3 clip；30s ≈ 50 词 ≈ 5–7 句。超预算精简台词而非拉长镜头（`handoff-contract.md` §四）。台词预算是**时长适配**，与**叙事节奏**是两件事——用户说"调整节奏"不等于"精简台词"，走 `narrative-pacing.md` 做叙事诊断；预算精简只在 film-director 回传超预算时做，且先重构场（合并/删冗余节拍/把信息挪到可见物件）再考虑削句。

## 五、双语坑：中文设计 → 英文台词

- **先写英文再对照**：先按角色声音写英文，再给中文对照；先写中文再直译会带出中式语序与成语比喻（用户项目里"钱比这还老"即直译事故 `[项目确认]`）。
- **中文意图 ≠ 英文措辞**：用户给的中文意思是意图锁，不是待翻译句；用英语母语者在此处境会说的话承载同一意图。
- **一秒落地测试**：听者（含非母语观众）一秒内能否听懂并知道说者要什么？需要二次解码的比喻（钥匙 / 名字能敲开门 / 钱比建筑老）在短剧里落不了地 `[项目确认]`；McKee 的"未说的"要能被听者读到，不是让听者猜谜。
- **不解释自己刚说的话**：解释上一句为何这么说的补句是作者在补漏 `[项目确认]`。
- **成语与俗语不过桥**；**名字少喊**（英文口语里直呼名字的频率低于中文习惯）`[推论]`；**中文对照只核意图**，不是第二版台词。

## 六、语域：美式青春 / 精英剧的当代英语 `[推论]`

短、具体、可说：对话句多为 3–12 词；名词具体（the Cup、the roster、your arm）不抽象（destiny、legacy）；俚语点到即止。正式场合仍是人话：致辞与训话用完整句与并列排比，但每句一个信息，短促收束比长从句更像台上的人。第三人称报道式旁白只陈述可见事实与规则，不评价、不点主角名 `[项目确认]`。

## 七、逐句检查（交付前过一遍）

1. 这句对听者做了什么？（Weston 动词；Mamet 三问）
2. 删掉少什么？（August）
3. 它在 McKee 的哪一层？听者能读到多少"未说的"？
4. 它在 Truby 的哪一轨？整场只有"故事对白"一轨吗？关键词有没有累积？
5. 说者此刻知道这件事吗？听者能接住吗？（郑瑞景）
6. 有没有在向观众解释 / 解释自己上一句？（Mamet；项目确认）
7. 听过的句子？（Rhimes）比喻一秒能落地吗？（项目确认）
8. 遮名能认出谁说的吗？这句让谁的地位上、谁下？（Johnstone）
9. 这场结束时什么变了？收尾句在哪？（McKee；朴海英：宁短勿总结）
10. 碰到引擎了吗，还是只在私人线（有意）？（`series-engine.md`）
11. 组织 / 赛事 / 头衔名与 `ip.md` 逐字一致吗？
12. 台词预算在 clip 内吗？读出声卡不卡？（Sorkin）
13. 英文是先写的还是译出来的？用户逐字给的句子原样在吗？

规则落地不等于质量已证明；创作增益仍以用户判断与盲测为准。
