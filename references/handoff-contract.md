# 协作契约：film-creative ↔ film-director

两份 skill 各存一份相同正文（本文件）。它回答一个问题：**一场戏从"台词定了"到"Prompt 出了"，谁交给谁什么，改了以后怎么同步。** 契约来自实际生产中反复出现的断点：台词到了生产侧没有说法与情绪、正典改了旧分镜还在表里、台词超长被长镜头硬装、修订后只给 diff 不给全文。范围、保存与确认仍由各自的执行契约裁决，本文件不新增审批。

## 一、交接物

| 交接物 | 谁写 | 谁读 | 何时必需 |
|---|---|---|---|
| 场景页（`03_script/scene-XX.md`）或账本行（台词 / 本场事件列） | film-creative | film-director | 对白场进入生产 |
| **台词设计表**（每句：目的动词 · 潜台词 · 说法 · 听者反应 · 情绪递进 · 收尾句标记；模板见 film-creative `templates/dialogue-design-sheet.md`） | film-creative | film-director：直接映射为每句〔说法〕、每镜〔情绪〕与【整体情绪弧线】，不重新推导 | 对白场进入生产时默认附；用户只要故事阅读稿时不附 |
| `ip.md`（人物 · 地点 · 视觉声音总则 · **正典变更表**） | film-creative 维护正典；用户直接改动同样有效 | 双方每次开工先读 | 始终 |
| **生产档案**（`production-profile.md`：画幅 · Prompt 语言 / 台词语言 · 素材绑定约定 · 调色段 · 声音与旁白策略 · 节奏约定 · 字幕 · 首帧策略 · 台词预算口径；模板见 film-director `templates/production-profile.md`） | film-director 建立与维护；首次从 `ip.md` §视觉声音总则与用户反复提出的要求提炼 | film-director 每条 clip 读；film-creative 读"台词预算"行 | 有生产的项目始终 |
| 时长预算回传（clip 秒数 → 台词预算：句数 / 词数） | film-director | film-creative | 台词超预算时 |
| 缺口 / 改词请求（只登记，不代改） | film-director | film-creative | 按需 |

台词设计表是**交接层**材料：它不进入可连续阅读的剧本正文，也不进入最终 Prompt；它是 film-director 编译〔说法〕〔情绪〕的来源，避免生产侧凭空补情绪或漏情绪。

## 二、账本模式（项目主表是分镜 / 台词表时）

很多项目的"当前正典时间线"不在 `02_story.md`，而在一张分镜与台词表（xlsx / csv）。这种情况下：

- **主表 = 时间线正典**，`ip.md` = 世界与人物正典。两者冲突以 `ip.md` 为准，并立即修表；不得让旧分镜靠"表里还在"继续存活。
- **列所有权**：film-creative 写 台词原句 · 中文对照 · 说法与重音 · 本场事件 · 叙事情绪；film-director 写 景别与运镜 · 画面与有序表演 · 光源与声音 · 连续性 / 起止状态 · 情绪与拍摄重点。镜号 / 入点 / 出点由 film-director 定，film-creative 只提出台词预算。
- **读表先于写**：开工先读目标镜前后各一段与"场景与连续性"页，再读 `ip.md`；不能只读用户最后一句。
- **版本**：单一主文件 + `_archive/`；版本号写在表头行与版本记录页，不按版本复制文件。
- **检查**：改表后跑 film-director `scripts/ledger_check.py`（时间连续 · 长镜含台词 · 机位单调 · 台词窗口）；改正典后跑 film-creative `scripts/canon_scan.py`（旧词漂移）。脚本只查可确定项，不判断故事或表演质量。

## 三、正典变更协议

改人设、改故事引擎、改造型、删角色时，按顺序做，不跳步：

1. film-creative 在 `ip.md`「正典变更」表加一行：旧 / 新 / 状态 / 波及范围（镜号、场次、clip）。
2. 跑 `canon_scan.py --ip ip.md <项目目录>`，列出旧词在表、场景页、Prompt 里的全部命中。
3. 逐条处理：改写 · 标〔待定〕留空 · 或写明"允许保留"的理由。**不得静默沿用旧分镜**；未出方向的段落留空并记明须保留的 canon 节拍。
4. film-director 对波及 clip 的 Prompt 重编译或标"待重写"，不 patch 旧镜头。
5. 命中清零或全部有处理记录后，才算同步完成。

## 四、时长与台词预算（生产侧对创作侧的反向压力）

- 估时口径：英语 2.5 词/s、中文 4 字/s（与 `validate_prompt.py` W05 相同）；对白占 clip 时长 ≤ 2/3。30s clip ≈ 20s 台词 ≈ 50 个英语词 ≈ 5–7 句。
- 台词超预算时，film-director 回传预算，film-creative 精简台词；**film-director 不拉长镜头承载超长台词**，也不擅自删词。
- 对白场默认一句一切、逐镜换景别 / 角度 / 运镜；一镜 ≥7s 只承载一句台词、或 ≥9s 承载对白，都要在 QA 写理由（W22 / W23 提示）。

## 五、交付默认

- film-creative 对白场：英文台词 + 中文对照 + 台词设计表；正文前两行写承接（上一场留下什么 / 本场交给下一场什么）；对白有收尾句（scene button）或明确写"无收尾、切下一场"。
- film-director：**每次交付（含每次修订）都给完整 Prompt 全文**（代码块），不是 diff、不是"改动处"；每镜〔情绪〕与每句〔说法〕取自台词设计表；无表时先在对话里补出并标"生产侧补写、待创作侧确认"。
- 双方修订都保留上一版可回看；改台词回 film-creative，改镜头回 film-director。

## 六、语言与格式

Prompt 语言与台词语言由生产档案决定（例：Prompt 中文、台词英文）；台词逐字加引号、带说话人与时间窗；不在 Prompt 里翻译台词。
