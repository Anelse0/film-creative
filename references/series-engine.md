# 系列引擎：先导片要立起的那台机器

用于先导 / 多集项目的 S3b–S3c，以及"后半段重排""这里叙事关系没串明白""缺少宣布赛事的戏份"一类批评。私人线（情感、背叛、被看见）是观众抓住的主体；**引擎**是让下一集还有事发生的机器（谁掌握什么决定权、每集必碰的规则或赛事、谁会因此得失）。反复出现的漂移是：故事只剩私人线，引擎在讨论里存在、在正文里消失。出处与证据强度见 `craft-sources-1.3.0.md`（G1 / D1 / M1 / T1 / Y1 / P1 / H1 / J1）。

## 1. 引擎一句话（写进 `ip.md`「故事引擎」）

一段话回答：**谁掌握什么决定权 · 决定通过什么可见机制落地（赛事、名单、投票、考核）· 每集必碰的场面 · 私人线在哪一类场面撞上引擎。** 写具体名词，不写主题词。检查：把这段话遮住，只读先导片正文，观众能否自己说出"这个剧以后每集会发生什么"？不能 → 引擎没立起。— G1 "明确这个剧是什么并反复传达"；D1 pilot 立起可重复处境与未解问题。

## 2. 对手与目标共享

真正的对手和主角要的是**同一样东西**（同一个位置、同一个名字、同一个人的承认），而不是各自忙各自的坏事。世家在册者 vs 新血抢同一投手位，比"坏人刁难新人"有戏；对手有自己的合理欲望（`screenwriting-methods.md` H2）。— T1 欲望 / 对手 / 计划；A3 中心戏剧论题由选择推进。

## 3. 每场三态判断：引擎在场吗

写每场前后各问一次，把答案记在台词设计表"引擎触点"一栏：

| 态 | 含义 | 处理 |
|---|---|---|
| 相交 | 一个事件同时支付私人线与引擎线（她被抢了署名，而抢她署名的人正因引擎新规则要被顶替） | 先导片最该有的场；优先保留 |
| 碰到 | 场面推进引擎（宣布、点名、递帖），私人线只在反应镜里 | 可以，但给主角一个可见反应或代价 |
| 仅私人线 | 场面只推进情感 / 关系 | 允许，需写明"有意"；连续两场都只在私人线时回查引擎是否已消失 |

"为写而写"的场多半属于第三态且不自知。— M1 三问：谁要什么 / 拿不到会怎样 / 为什么是现在。

## 4. 场与场之间用"因此 / 但是"相连

相邻场景能互换顺序而无损 → 中间只是"然后"。后一场应当由前一场的结果推出（因此）或被前一场的结果阻挡（但是）。宣布规则之后的下一场，要有人因规则做了原本不会做的事。— P1 therefore / but；Y1 每场局部弧（`stage-3b-story.md` §3b.2 第二问）。

五分钟先导里的铺垫要在片内兑现且不显得像铺垫：先让它作为当下的行动或玩笑成立，兑现时观众才回想起来（Scriptnotes 693，A4 `[一手]`）。

## 5. 观众何时知道：宣布不揭结果

- 先导片宣布赛制、候选、淘汰规则；**不宣布赢家**，把"谁留谁走"留给后续。
- 观众先于人物知道（炸弹在桌下）产生悬念；观众与人物同时知道产生意外；两者各自适合的场面不同，选一种写清。
- 被当众点名的人，其他人物"认出他"的游戏就失效；正典改动后重查依赖旧信息差的场（本项目露台段即此例）。— H1；`stage-3b-story.md` §3b.2 第三问。

## 6. 亮相与地位

群像剧要让观众在第一分钟知道谁是谁（《Élite》主创，E1 `[一手访谈报道]`）。人物首次亮相靠**他人的反应**建立地位（人群让道、停杯、转头、对手的下颌），再给本人的特写；介绍先行，特写作揭示（生产侧规则见 film-director stage-5 5.1d 与 dialogue-pacing §4）。魅力不是形容词，是他人对他的反应速度与他对目光的回应方式。— J1 status。

## 7. 正典改动的波及

引擎或人物角色改变（守门人→队长、删角色、改造型、改动机）时：
1. `ip.md` 正典变更表登记旧 / 新 / 状态 / 波及；
2. `scripts/canon_scan.py` 扫旧词；
3. 逐场重问 §3 三态与 §5 信息差是否仍成立；不成立的场**留空标〔待定〕**，不用旧逻辑硬套；
4. 保留必须留下的 canon 节拍（台词锁、母题句）写在留空处的备注里。

行业对照：编剧室设专人维护剧本圣经与时间线，逐项记录每个人物的细节供查证（《Lost》Gregg Nations，N1 `[一手报道]`）；锁稿后的改动用彩页轮换与边栏星号标出改动行（Final Draft / Celtx，F2）。本 skill 的对应物是 `ip.md` 正典变更表（谁改了什么）+ `canon_scan.py`（改动波及到哪）。

## 8. 先导片检查（交付前十问）

1. 遮住引擎段落，正文能否让观众说出"以后每集会发生什么"？
2. 对手与主角要的是同一样东西吗？
3. 有几场是"相交"？为零就重排。
4. 连续两场只在私人线？是有意的吗？
5. 相邻场能互换而无损吗？
6. 规则宣布了，下一场有人因它改变行动吗？
7. 结果揭了吗？揭了就收回。
8. 观众先知还是同知？每个揭示写清一种。
9. 主角亮相有他人反应吗？
10. 正典改过的地方，扫过漂移了吗？

方法来自一手与转述资料的提炼与项目实践，不是效果证明；创作增益以用户判断与盲测为准。
