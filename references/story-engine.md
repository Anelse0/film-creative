# 故事引擎：前提怎样持续产生事件，观众为什么在乎

S3a 判断概念能否发展成故事、S3b 组织多场 / 多集、诊断"中段只是换景约会"时读。单场独立短片、观察性作品不必逐项套用；本文件是判断工具，不是每个故事都要填的表。方法来源与已读范围见 `context-creativity-sources.md` §3.0.0。

核心判断贯穿全部：**不要只判断发生了什么，要判断这件事让人物之间发生了什么变化，以及观众为什么在乎。**

## 一、概念只是入口：它能不能持续产生事件

"宿敌相爱""竞争同一个位置"是入口，不是引擎。引擎是一个会反复运转的处境：谁掌握决定权、决定通过什么可见节点落地（考核、名单、赛程、投票、交接）、每隔多久必须再碰一次、私人关系在哪类节点上会撞上它。

| 判断 | 证据 | 修复 |
|---|---|---|
| 遮住开头的高概念，只读中段：事件还是由这个前提产生的吗 | 中段若换成任何两个同事也成立，前提已经失效 | 给机制加周期性的公开节点，让节点之间的私人选择能改变节点的结果 |
| 第 N 集 / 第 N 场还有事发生吗（"what is episode 100"） | 只能靠新秘密、新反派、新事故续命 | 从上一次选择的代价找下一件事；机制不够时改机制，不加灾难 |
| 相邻段落之间是"因此 / 但是"，还是"然后" | 互换顺序无损，说明中间只是"然后" | 写出前一段留下的结果如何逼出后一段（Parker & Stone：beats 之间应是 therefore 或 but，不是 and then） |

例外：观察性、平行叙事或单一时刻的短片不靠机制成立，按 `character-scene-development.md` §二 判断承载；不为它们硬造赛制。

## 二、外部剧情与私人关系互相改变

两条线各自成立不等于故事成立。

| 判断 | 证据 | 修复 |
|---|---|---|
| 换掉这次外部事件，这场私人戏是否原样成立 | 是 → 外部只是背景 | 让外部事件改变两人此刻能做什么、敢说什么、欠谁什么 |
| 换掉两人此刻的关系状态，这次外部事件是否原样发展 | 是 → 关系不影响世界 | 让关系中的一个选择改变外部结果（谁上场、谁签字、谁说了什么公开话） |
| 一个选择能否同时支付两条线 | 每集都要分别写一场事业戏、一场感情戏 | 找正在进行的任务，让关系中的牵引在任务内部发生（`screenwriting-methods.md` K2） |

不强求每场同时承担全部功能；连续多场两线互不触碰时才是问题。

## 三、为什么被吸引、为什么持续交集、靠近要付什么

**吸引要有证据。** 观众看见的是能力、幽默、对不如自己的人的态度、被对方反驳时的反应，不是形容词。"她很有魅力"不是证据；"她在众人起哄时替失误的人解围"是。每个人都要有独立于爱情之外的欲望与生活；对方只是其中一部分。

**交集要有理由。** 两人反复相遇靠制度、赛程、空间的强制，不靠巧合。稀缺才有张力：被迫同处的场合越少、越公开，每次见面越重。

**靠近要有代价。** 每一步靠近付出什么：时间、公开身份、对队友 / 家人的忠诚、自尊、在竞争中的优势。没有代价的靠近只是变慢。

**确认关系不是失去张力，长期不确认也不是拥有张力。** 关系每进一阶，写出新的可能与不可能：

```
阶段变化后：哪些选择变得可能 / 不再可能；谁新获得了伤害对方的能力；下一次公开场合他们各自要怎样表现
```

Tierney 谈《Heated Rivalry》："I don't think romance can go on indefinitely… you're doing a disservice to these characters by endlessly trafficking the will-they-or-won't-they" `[一手访谈]`；同一季末集全无冰球戏，靠两人的坦诚与玩笑成立 `[一手访谈]`。本 Skill 据此把"确认后的新后果"当作张力来源之一 `[推论]`。

## 四、情绪推进靠触发，不靠宣布

人物的情绪变化要能回答三件事：他经历了什么 → 此刻什么触发了他 → 他因此做了什么与平时不同的事。Gilligan 的编剧室问题是 "Where is Walt's head at? What does he want right now? What is he afraid of?" `[一手访谈]`。

**隐瞒、误会、退缩的三问**（写之前答，答不出就别用）：

1. 他为什么此刻不能说？（羞耻、忠诚、不确定对方、说了会输掉什么）
2. 不说会付出什么代价，什么时候付？
3. 观众知道他知道吗？观众比他多知道什么？

不可用：性格突变、降低智力、能一句话澄清却不澄清、只为拖到下一集的误会。可用：有具体理由的不说。《Normal People》的不沟通成立，是因为羞耻、阶层与社交焦虑给了它理由，而不是因为剧情需要 `[第三方分析 + 编剧访谈]`。

## 五、世界不只有两位主角

| 判断 | 证据 | 修复 |
|---|---|---|
| 删掉这个配角，主角的某个选择会不会消失 | 不会 → 他只是传话筒或背景 | 给他一个与主角利益相关、可能冲突的目标，让他的行动改变主角的选项 |
| 换一个场景，暴露的是新的身份 / 关系 / 压力，还是只换了背景 | 同一种约会换了地点 | 让新空间里有别人的规则、别人的目光、主角不同的权力位置 |
| 同一地点还有新的戏剧作用吗 | 有 → 不必强行换景 | 重访时改变谁掌握主动、谁看见了什么 |

配角不必轮流发表观点，也不必每个都有小传；他要的东西在行动里出现即可。

## 六、观看欲望从哪里来

不只避免坏剧本。逐段问：观众在哪里得到心动、担忧、惊讶、好笑或情绪释放？一段 / 一集都答不出时，这里就是最先要修的地方。

- 期待要被具体建立：观众知道人物想要什么、怕什么（Mazin："fear is our connection to a character" `[一手文字稿]`），才会为下一步担心。
- 兑现要发生：不能只吊胃口。承诺过的相遇、对峙、允许要真的发生，发生时有代价或变化。
- 给的信息刚够：Gilligan："give the audience just enough that the show is interesting… keep them right on the edge" `[一手访谈]`。
- 魅力、快乐与情感回报不是失控，克制不等于删掉它们。

## 七、写法：先写会发生什么

故事正文与分集框架写**观众会看见的事**：谁在哪里做了什么，对方怎么回应，结果是什么。"没有靠误会推进""没有突然和解""不是富人羞辱穷人"这类否定句留在自检，不进正文——正文里的否定句只说明作者避开了什么，不能让观众看见任何东西。写完通读：若一段里否定句多于陈述句，重写成陈述。

## 八、误用信号

- 为了"机制"给不需要的故事加赛制、考核、投票。
- 为了"配角有目标"塞进新人物，而不是先让已有配角起作用。
- 把"靠近有代价"写成每次亲近后必有惩罚。
- 因为出现了告白、误会、同一地点、直接表达，就判定失败；这些是值得检查的信号，不是已确认的问题。
- 用"观众此刻会心动"之类的说明代替正文里能让人心动的具体事。
